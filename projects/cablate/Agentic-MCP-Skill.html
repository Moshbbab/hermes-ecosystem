overview

Agentic-MCP-Skill is an experimental MCP client designed to reduce token consumption through a three-layer progressive disclosure pattern. It implements a socket-based daemon architecture that allows AI agents to load server metadata, tool lists, and specific tool schemas incrementally rather than all at once. This approach aims to optimize context window usage and improve the efficiency of managing multiple MCP servers.

  • Three-layer progressive loading to minimize token usage
  • Socket-based daemon architecture for persistent connections
  • Incremental discovery of server metadata and tool schemas
