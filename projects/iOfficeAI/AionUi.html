overview

AionUi is an open-source cowork platform designed to let AI agents work alongside users by performing tasks like file editing and web browsing. It features a built-in agent engine that requires zero configuration and supports various API keys for immediate use. The platform unifies multiple CLI agents into a single interface and provides remote access via web and messaging apps. Users can automate complex workflows and generate editable Office documents like PPT, Word, and Excel.

  • Built-in agent engine with zero configuration
  • Unifies multiple CLI agents in one interface
  • Automates document creation for PPT, Word, and Excel
