overview

Doomsday is a Proof-of-Work cryptocurrency designed to mine on consumer GPUs when a computer is idle, pausing mining when the user interacts with it. The project also provides a Windows desktop client, a live network dashboard, and a 1:1 bridge between DOOM and wDOOM on Base Mainnet.

  • Uses DoomHash and ASERT difficulty retargeting.
  • Targets a 20-second block time.
  • Desktop client supports idle mining modes.
