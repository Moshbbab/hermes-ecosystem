breakdown

numtide / llm-agents.nix

This project provides daily-updated Nix packages for a wide variety of AI coding agents, including Hermes, ensuring users always have access to the latest versions. It simplifies deployment by allowing agents to be executed directly via nix run commands without manual installation.

marshallrichards / ClawPhone

ClawPhone offers an automated installer and configuration guides for running Hermes Agent and Antigravity CLI on ARM64 Android devices via Termux. It uniquely leverages Termux:API and Termux:GUI to grant the agent access to smartphone hardware and user interface elements.

rookiemann / portable-hermes-agent

This Windows-native distribution requires no installation, admin rights, or Docker, making it the most accessible option for desktop users. It features a built-in workflow engine and over 100 integrated tools, including TTS and ComfyUI, for automated local pipelines.

AbuZar-Ansarii / Hermes-Agent-On-Android

Designed for rapid mobile deployment, this project uses a one-line script to set up Hermes Agent within the Termux environment. It prioritizes privacy and low latency by supporting local AI execution through Ollama alongside 200+ cloud-based models.

ultraworkers / hermes-agent-helm-chart

This community Helm chart enables cloud-native deployment of Hermes Agent on Kubernetes with a focus on state safety. It enforces single-writer persistence for agent storage and supports both direct deployments and operator-ready workflows.

TheAiSingularity / hermesclaw

Hermesclaw focuses on high-security environments by providing hardware-level enforcement of network, filesystem, and process boundaries. It offers three distinct security presets and integrates with external platforms like Discord and VS Code via the Agent Control Protocol.

xmbshwll / hermes-agent-docker

This project provides a streamlined Docker sandbox that bundles the official Hermes installation with mini-swe-agent. It supports persistent state through mounted directories and allows users to build specific agent versions using Docker build arguments.

0xrsydn / nix-hermes-agent

This NixOS module enables declarative management of Hermes configurations, documents, and systemd services for reproducible deployments. It features robust secrets handling via sops-nix and supports a hybrid model for both Nix-managed and interactive CLI skills.

jpalmae / hermeshq

HermesHQ acts as a Docker-based control plane for orchestrating multiple agent instances with distinct identities and workspaces. It is built for scale, offering hierarchy-aware task delegation and enterprise MCP access for external AI client integrations.

JackTheGit / hermes-autonomous-server

Targeting production environments, this project configures the Hermes Gateway as a reboot-safe systemd service on Ubuntu and Debian. It is optimized for headless operation, allowing the agent to execute autonomous cron jobs and integrate with the Nous Portal.

ellickjohnson / portainer-stack-hermes

This deployment stack integrates Hermes into the Portainer UI as a Git-managed repository for easy container management. It includes ttyd to provide a convenient web-based terminal interface for interacting with the agent through any browser.
