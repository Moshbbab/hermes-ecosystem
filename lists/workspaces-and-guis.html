breakdown

farion1231 / cc-switch

This cross-platform manager, built on the Tauri 2 framework, provides a unified interface for Windows, macOS, and Linux users. It allows for the simultaneous management of Hermes Agent alongside other AI agents and CLI tools in a single application.

iOfficeAI / AionUi

AionUi is a local cowork application that unifies multiple CLI agents into one interface with a zero-configuration built-in engine. It distinguishes itself by automating the creation of office documents, including PowerPoint, Word, and Excel files.

nesquena / hermes-webui

This web-based interface offers full parity with the Hermes CLI experience for both desktop and mobile browsers. It features a three-panel layout for workspace file browsing and utilizes SSH tunneling to provide secure remote access.

fathah / hermes-desktop

A desktop companion app designed to simplify the initial setup of Hermes Agent through guided installation and provider configuration. It provides a graphical interface for managing chat sessions, tools, and multiple AI providers.

EKKOLearnAI / hermes-web-ui

This dashboard focuses on multi-platform connectivity, offering unified configuration for channels like Telegram, Discord, Slack, and WhatsApp. It includes a file browser and web terminal while providing usage analytics and profile-scoped file management via local SQLite storage.

outsourc-e / hermes-workspace

This native web workspace features a 'Swarm Mode' with role-based dispatch and tmux-backed workers for complex task handling. It integrates a Monaco-based file browser, a PTY terminal, and dedicated managers for skills, memory, and MCP catalogs.

dodo-reach / hermes-desktop

A native Mac workspace that provides direct local or SSH connections to Hermes hosts for real-time session data. It includes specialized native views for Kanban boards, cron jobs, and an embedded terminal for system repair and shell access.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension integrates Hermes Agent directly into the browser context for Chrome and Edge users. It can connect to local runtimes, Hermes Cloud, or remote gateways to provide a full-page web workspace.

Eynzof / hermes-agent-cn-desktop

Built with Tauri, TypeScript, and Rust, this Windows-first desktop application includes a built-in Hermes-CN-Core runtime. It is specifically designed to support LaTeX and Markdown rendering for enhanced document visualization.

xaspx / hermes-control-interface

This self-hosted dashboard features a ZOO Swarm Monitor for tracking agent health and kanban pipelines in real-time. It provides a control plane for managing MCP server lifecycles and visualizes tool calls during streaming chat sessions.

jazzyalex / agent-sessions

A native macOS cockpit that tracks per-session quota burn-rates and costs across Hermes and other coding-agent CLIs. It allows users to inspect transcripts and browse images generated during agent sessions.

nickvasilescu / hermes-desktop-os1

This macOS workspace is tailored for Orgo cloud computers and SSH hosts, offering one-click automated installation on fresh cloud VMs. It features an integrated WebRTC voice mode that utilizes OpenAI Realtime and Orgo MCP.

liftaris / herm

Built with OpenTUI, this terminal-based dashboard consolidates Hermes chat, sessions, and configuration into a TUI. It includes integrated kanban boards for diagnostics and an extensible Eikon avatar system for lifecycle management.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA designed for Telegram, supporting dual HMAC-SHA256 and Ed25519 authentication. It enables background agent spawning with support for up to five concurrent instances and streaming terminal chat.

aivrar / portable-hermes-agent

This no-install Windows application requires no admin rights or Docker to run Hermes Agent locally via LM Studio. It includes a workflow engine for multi-step automation and 100 built-in tools for tasks like TTS and ComfyUI.

pyrate-llama / hermes-ui

This self-hosted assistant features a glassmorphic web interface with real-time log streaming and task tracking. It provides management tools specifically for skills, cron jobs, and MCP servers alongside an integrated file browser.

sanchomuzax / hermes-webui

A specialized monitoring dashboard that provides read-only inspection of environment variables and configuration. It allows users to track session costs in real-time and inspect the source code of active skills and conversation histories.

Euraika-Labs / pan-ui

This self-hosted workspace uses isolated profiles to manage separate sessions, memory, and API keys. It features a chat-first design with tool approval cards and an integrated marketplace for discovering new skills and MCP servers.

Felix-Forever / hermes-agent-desktop

This desktop client orchestrates collaboration between 20 specialized AI agents for complex tasks. It includes a visual Skill Store with over 50 one-click installations and supports model switching with streaming SSE responses.
