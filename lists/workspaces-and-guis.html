breakdown

farion1231 / cc-switch

CC Switch is a cross-platform manager for Hermes Agent and several other agent tools, including Claude Code, Codex, OpenCode, OpenClaw, and Gemini CLI. It lets users switch API providers in one click and manage MCP, Skills, and Prompts in one place, with support for Windows, macOS, and Linux.

iOfficeAI / AionUi

AionUi is a local open-source cowork app for Hermes Agent and other agent CLIs, with a built-in agent that does not require a separate CLI installation. It also includes 21 professional assistants and supports macOS, Windows, and Linux.

nesquena / hermes-webui

Hermes WebUI provides a three-panel interface for sessions, chat, and workspace files, with controls for profiles, models, and workspaces. Built with Python and vanilla JavaScript, it requires no build step and is designed for using Hermes Agent from the web or a phone.

fathah / hermes-desktop

Hermes Desktop is a desktop companion for installing, configuring, and chatting with Hermes Agent, using the official Hermes install script. Its GUI manages profiles, sessions, skills, and tools, and the app is available from the project website or GitHub Releases.

EKKOLearnAI / ekko-studio

Ekko Studio is a web dashboard for Hermes Agent that brings together chats, sessions, agent integrations, scheduled jobs, usage analytics, and channel configuration. It also supports visual workflows with schedules and approval gates, and is available as a desktop app, npm CLI, or Docker image.

outsourc-e / hermes-workspace

Hermes Workspace is a web workspace combining chat, a terminal, a memory browser, a skills manager, and an inspector panel. Its highlights include Swarm Mode with role-based dispatch and tmux-backed workers, plus a file browser with Monaco and a PTY terminal.

spacering-net / codeg

Codeg is a collaborative coding workspace that aggregates sessions from Hermes and other agents, including Claude Code, Codex, and OpenCode, as a desktop or self-hosted app. Users can import, search, resume, and hand off sessions, delegate across agents, or queue to-dos in worktrees.

dodo-reach / hermes-desktop

This native Mac workspace connects directly to Hermes hosts locally or over SSH and presents sessions, Kanban, skills, and cron jobs in dedicated views. Its embedded terminal provides direct shell access, including for system repair.

Eynzof / Hermes-CN-Desktop

Hermes-CN-Desktop is a Windows-first desktop app for Hermes Agent, supporting Windows and macOS with native window and process management. It includes a built-in Hermes-CN-Core kernel with health checks and updates, alongside chat, memory management, and LaTeX and Markdown rendering.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension connects the active browser context to a local, Hermes Cloud, or self-hosted remote Hermes Agent runtime. It offers Bot Mode for agent switching and group chats; Hermes Control is opt-in and Chromium-only.

uzairansaruzi / hermex

Hermex is a native SwiftUI iPhone app for driving a self-hosted Hermes agent by pairing with a hermes-webui server. It supports streaming chats with file or image attachments and lets users browse, search, and resume sessions, as well as view scheduled tasks, skills, memory, and insights.

freestylefly / wesight

Wesight is a desktop AI agent workspace with one-click setup for Hermes Agent, Claude Code, Codex, and OpenClaw, along with custom LLM model routing. Its runtime dashboard tracks token usage and latency, while a live workspace shows code writes and diffs.

joeynyc / hermes-hud

Hermes HUD is an interactive TUI with nine tabs and four selectable color themes for monitoring Hermes. It tracks agent growth, Git projects, and scheduled cron jobs, and provides a tmux operator view for managing live agent panes.

jazzyalex / agent-sessions

This native macOS app brings together session browsing, analytics, and quota tracking for Hermes agents and other coding-agent CLIs. It searches prompts, tool activity, errors, and file paths, tracks Codex and Claude quota burn per session, and builds its search index locally.

xaspx / hermes-control-interface

This self-hosted web dashboard provides a browser-based interface to the Hermes AI agent stack, including a terminal, file explorer, session overview, cron management, system metrics, and agent status panel. Its highlights also include real-time chat with tool-call visualization, MCP server lifecycle controls, and a ZOO Swarm Monitor for agent health and kanban pipelines.

nickvasilescu / hermes-desktop-os1

This native macOS workspace runs Hermes Agent on Orgo cloud computers and SSH hosts. It offers one-click automated installation on fresh cloud computers and integrated WebRTC voice mode using OpenAI Realtime and Orgo MCP.

sharbelxyz / hermes-agent-mission-control

This self-hostable mission-control dashboard template connects a local Hermes agent to web dashboards through a Postgres message bus. Its approval inbox lets users review requests with side effects before they proceed.

liftaris / herm

Herm is an alternative Hermes TUI and dashboard built with OpenTUI for chatting and managing agent sessions. It also includes a kanban board for agentic work and tools for managing profiles, skills, cron jobs, and toolsets.

clawvader-tech / hermes-telegram-miniapp

This locally run React SPA is a 10-page, mobile-first dashboard for Telegram Mini App v2.0. It combines terminal chat with streaming responses and file attachments, Telegram validation using dual HMAC-SHA256 and Ed25519 authentication, and background agent spawning for up to five concurrent instances.

aivrar / portable-hermes-agent

This project packages Hermes Agent as a portable Windows desktop app with a dark-themed, multilingual GUI and session management. It supports local models through LM Studio and includes workflow automation and runtime tool creation.

pyrate-llama / hermes-ui

Hermes UI is a self-hosted assistant interface with a glassmorphic design, chat, and real-time log streaming. It also provides a file browser, task tracking dashboard, and management tools for skills, cron jobs, and MCP servers.

sanchomuzax / hermes-webui

This dashboard focuses on monitoring Hermes processes and configuring the system. It shows session activity and costs in real time, supports inspection of conversation histories and skill source code, and provides read-only views of configuration and environment variables.

Euraika-Labs / pan-ui

Pan-UI is a self-hosted, chat-first AI workspace with real-time SSE streaming and tool approval cards. Its marketplace supports discovering and installing skills and MCP servers, while isolated profiles keep sessions, memory, and API keys separate.

Felix-Forever / hermes-agent-desktop

This native desktop client centers on multi-agent collaboration, with 20 specialized AI agents and a PM orchestrator. It also offers a visual Skill Store with 50+ curated one-click installations, streaming SSE responses, and model switching.

nicolasestrem / hermes-model-switcher

This plugin displays configured model routes across Hermes Agent profiles in one matrix and lets you preview changes before applying them. Named presets and guarded Undo make it a focused option for switching models from the Hermes Agent Web Dashboard.

robbyczgw-cla / hermes-ui-plus

This unofficial, open-source chat client for self-hosted Hermes Agent supports interactive answers such as checklists, choices, forms, rankings, and votes. It also provides command approvals and live tool-step updates, with clients for Android, web, and macOS plus a Linux alpha.
