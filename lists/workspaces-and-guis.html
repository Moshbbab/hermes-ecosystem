breakdown

farion1231 / cc-switch

A Tauri 2-based cross-platform manager for Windows, macOS, and Linux. It provides an all-in-one interface to manage Hermes Agent alongside other agentic tools and CLI models.

iOfficeAI / AionUi

A local open-source cowork app for macOS, Windows, and Linux that includes a built-in agent engine with file access. It specializes in automating the creation of Word, Excel, and PPT documents.

nesquena / hermes-webui

A Python and vanilla JavaScript web interface that provides full parity with the Hermes CLI experience. It features a three-panel layout combining chat with workspace file browsing.

fathah / hermes-desktop

A desktop companion app focused on the initial setup of Hermes Agent through guided installation and provider configuration. It includes a GUI for managing tools, sessions, and chat across multiple AI providers.

EKKOLearnAI / hermes-web-ui

A web dashboard featuring usage analytics, scheduled jobs, and profile-scoped file management via local SQLite storage. It provides unified configuration for channels including Telegram, Discord, Slack, and WhatsApp.

outsourc-e / hermes-workspace

A native web workspace featuring a PTY terminal, Monaco editor, and an MCP catalog. It implements Swarm Mode with role-based dispatch and tmux-backed workers.

dodo-reach / hermes-desktop

A native Mac workspace that connects to Hermes hosts via local or SSH connections. It provides native views for Kanban, skills, and cron jobs, alongside an embedded terminal for system repair.

Eynzof / hermes-agent-cn-desktop

A Windows-first desktop application built with Tauri, TypeScript, and Rust that supports Windows and macOS. It includes a built-in Hermes-CN-Core runtime and supports Markdown and LaTeX rendering.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension for Chrome and Edge that connects browser context to local or remote Hermes Agent runtimes. It includes Hermes Web for full-page workspace sessions.

xaspx / hermes-control-interface

A self-hosted web dashboard featuring tool call visualization and a ZOO Swarm Monitor for tracking agent health. It includes an MCP server control plane to manage server lifecycles.

jazzyalex / agent-sessions

A local-only macOS session browser and cockpit that tracks quota burn-rates per session. It supports Hermes and other coding-agent CLIs including Codex, Claude, Cursor, and GitHub Copilot CLI.

nickvasilescu / hermes-desktop-os1

A native macOS workspace designed for Hermes Agent running on SSH hosts and Orgo cloud computers. It offers one-click automated installation on cloud VMs and integrated WebRTC voice mode.

liftaris / herm

This OpenTUI-based terminal dashboard consolidates Hermes Agent chat, sessions, and configuration into a single interface. It features integrated kanban boards for managing agentic tasks and an extensible Eikon avatar system with catalog browsing.

clawvader-tech / hermes-telegram-miniapp

A React-based mobile-first SPA designed for Telegram Mini App v2.0 that runs locally. The interface supports terminal chat with streaming responses and file attachments, while allowing for five concurrent background agent instances.

aivrar / portable-hermes-agent

A no-install, admin-free Windows desktop application that provides a GUI for Hermes Agent without requiring Docker. It includes a workflow engine for multi-step automation and 100 tools, including extensions for TTS, Music, and ComfyUI.

pyrate-llama / hermes-ui

A glassmorphic web interface designed for self-hosted AI assistance. It provides real-time log streaming and chat alongside a task tracking dashboard, file browser, and management tools for skills, cron jobs, and MCP servers.

sanchomuzax / hermes-webui

This dashboard provides real-time monitoring of session activity and cost tracking. It allows for full inspection of conversation histories and skill source code, as well as read-only monitoring of environment variables and configuration.

Euraika-Labs / pan-ui

A self-hosted workspace featuring a chat-first interface with real-time SSE streaming and tool approval cards. It includes an integrated marketplace for skills and MCP servers, plus isolated profile management for memory and API keys.

Felix-Forever / hermes-agent-desktop

A native desktop client designed for orchestrated collaboration between 20 specialized AI agents. It features a visual Skill Store with over 50 curated installations and supports streaming SSE responses and model switching.
