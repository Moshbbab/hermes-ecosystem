breakdown

farion1231 / cc-switch

This Tauri 2-based manager provides a cross-platform interface for Windows, macOS, and Linux users to handle multiple agentic tools. It serves as an all-in-one hub for managing Hermes Agent alongside other command-line tools like Claude Code and Gemini CLI.

iOfficeAI / AionUi

AionUi is a local coworking application that enables 24/7 scheduled automation for Hermes Agent via Cron. It supports remote access through WebUI and messaging platforms like Telegram, featuring 21 built-in assistants for generating office documents.

nesquena / hermes-webui

Built with Python and vanilla JavaScript, this interface allows users to access Hermes Agent through a web browser or SSH tunnel. It includes a workspace file browser with inline previews, optimized for both desktop and mobile use.

fathah / hermes-desktop

This desktop companion simplifies the initial experience by providing guided installation and provider setup for Hermes Agent. The application includes a graphical user interface for managing chat sessions, tools, and multiple AI providers.

EKKOLearnAI / hermes-studio

This web dashboard offers comprehensive management of Hermes Agent through visual workflow builders, Kanban boards, and usage analytics. It supports streaming responses and tool traces while facilitating communication across ten platform channels including Discord and WhatsApp.

outsourc-e / hermes-workspace

This native web workspace features a 'Swarm Mode' with role-based dispatch and tmux-backed workers for complex tasks. It integrates a Monaco-based file browser, a PTY terminal, and a dedicated catalog for managing skills and MCP tools.

xintaofei / codeg

Codeg is a collaborative coding workspace that aggregates sessions from Hermes and other agents into a single desktop or self-hosted environment. It supports thirteen built-in agents and offers native mobile clients for both iOS and Android.

dodo-reach / hermes-desktop

Designed as a native Mac workspace, this tool provides direct local or SSH connections to Hermes hosts with a real terminal for system repair. It features native views for managing sessions, skills, and cron jobs directly from macOS.

Eynzof / Hermes-CN-Desktop

This Windows-first desktop application, built with Tauri and Rust, includes the Hermes-CN-Core kernel for local agent execution. The interface supports LaTeX and Mermaid rendering while providing native dialogs for memory and MCP tool management.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension links active browser context to local or remote Hermes runtimes. It features 'Hermes Assist' for site-aware drafting across 31 writing environments and a dedicated web interface for full-page session management.

uzairansaruzi / hermex

Hermex is a native SwiftUI application for iOS 18+ that allows users to drive a self-hosted Hermes Agent from an iPhone. It pairs with a web server to provide mobile management of agent tasks, skills, and read-only access to memory analytics.

freestylefly / wesight

This desktop workspace offers one-click setup for Hermes Agent and features a runtime dashboard for tracking token usage and latency. It provides a live monitoring environment for observing code writes and diffs in real-time.

xaspx / hermes-control-interface

This self-hosted web dashboard provides a comprehensive control plane for managing MCP server lifecycles and ZOO Swarm kanban pipelines. It features a browser-based terminal, real-time chat with tool call visualization, and a dedicated status panel for monitoring agent health and system metrics.

jazzyalex / agent-sessions

A native macOS session browser and cockpit designed to track analytics and limits for Hermes alongside various other coding-agent CLIs. It offers searchable transcript history, image browsing, and live per-session quota burn-rates for specific models like Codex and Claude.

nickvasilescu / hermes-desktop-os1

This native macOS workspace facilitates one-click automated Hermes Agent installations on Orgo cloud VMs and SSH hosts. It distinguishes itself by integrating a WebRTC voice mode that utilizes OpenAI Realtime and Orgo MCP for audio-based interaction.

sharbelxyz / hermes-agent-mission-control

Built with Next.js 16 and React 19, this dashboard template uses a Postgres message bus to bridge local agents with a web-based interface. It specifically includes an approval inbox designed to manage agent requests that result in side effects.

liftaris / herm

This alternative interface uses OpenTUI to provide a terminal-based dashboard for chatting and managing Hermes Agent sessions. It incorporates a kanban board for task management and allows users to configure profiles, skills, cron jobs, and toolsets within the TUI.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA dashboard designed for Telegram Mini App v2.0 that supports background agent spawning for up to five concurrent instances. It features terminal chat with file attachments and secures sessions using dual HMAC-SHA256 and Ed25519 authentication.

aivrar / portable-hermes-agent

This Windows desktop GUI requires no installation, Docker, or admin rights, offering a portable solution for running Hermes with local models via LM Studio. It includes a dynamic tool maker for creating API and Python handlers and supports integrated workflows for TTS and ComfyUI.

pyrate-llama / hermes-ui

A glassmorphic web interface that provides real-time log streaming and a task tracking dashboard for the self-hosted AI assistant. It includes dedicated management tools for organizing skills, cron jobs, and MCP servers through a browser-based file explorer.

sanchomuzax / hermes-webui

This monitoring dashboard focuses on process oversight by providing real-time session activity and cost tracking for Hermes. It allows for full inspection of conversation histories and skill source code, alongside read-only monitoring of environment variables.

Euraika-Labs / pan-ui

A self-hosted workspace featuring a chat-first design with tool approval cards and real-time SSE streaming. It includes an integrated marketplace for discovering MCP servers and supports isolated profile management for maintaining separate memory and API keys.

Felix-Forever / hermes-agent-desktop

This native desktop client enables orchestrated collaboration between 20 specialized AI agents managed by a PM orchestrator. It features a Visual Skill Store with over 50 one-click installations and supports streaming SSE responses with on-the-fly model switching.
