breakdown

farion1231 / cc-switch

A cross-platform manager built with Tauri 2 that supports Windows, macOS, and Linux. It provides a unified interface for managing multiple agentic tools, including Hermes Agent, Claude Code, and Gemini CLI.

iOfficeAI / AionUi

A local open-source cowork application that unifies multiple external agents like OpenClaw and Hermes Agent into a single interface. It offers remote access through WebUI and various messaging platforms, including Telegram, Lark, DingTalk, and WeChat, and includes 21 built-in professional assistants.

nesquena / hermes-webui

A Python and vanilla JS-based web interface designed for accessing Hermes Agent via a browser or SSH tunnel. It features a workspace file browser with inline preview capabilities.

fathah / hermes-desktop

A desktop companion app that facilitates the installation and configuration of Hermes Agent and its providers. It provides a graphical user interface for managing chats, sessions, and tools.

EKKOLearnAI / hermes-studio

A web dashboard that supports multi-platform AI chat, session management, and scheduled jobs. It includes visual workflow building, Kanban boards, usage analytics, and channel configuration for 10 platforms such as Telegram, Discord, and Slack.

outsourc-e / hermes-workspace

A native web workspace featuring an integrated terminal, memory browser, skills manager, and inspector panel. It utilizes tmux-backed workers for Swarm Mode with role-based dispatch and includes a Monaco-based file browser.

xintaofei / codeg

A collaborative multi-agent coding workspace that aggregates sessions from Hermes, Claude Code, and Codex. It supports task delegation to sub-agents and is available as a desktop or self-hosted app with native iOS and Android clients.

dodo-reach / hermes-desktop

A native Mac workspace that connects directly to Hermes hosts via local or SSH connections. It provides native views for sessions, Kanban, skills, and cron jobs, alongside an embedded terminal for shell access and system repair.

Eynzof / Hermes-CN-Desktop

A Windows-first desktop application built with Tauri, TypeScript, and Rust that also supports macOS. It includes a built-in Hermes-CN-Core runtime and supports LaTeX and Markdown rendering.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension that connects active browser contexts to local, cloud, or remote Hermes Agent gateways. It features Hermes Assist for site-aware drafting in 31 writing environments and Hermes Web Alpha for session and runtime management.

uzairansaruzi / hermex

A native SwiftUI app for iOS 18+ that pairs with a hermes-webui server to drive self-hosted Hermes agents. It allows users to manage sessions, tasks, and skills, while providing read-only access to agent memory and analytics.

freestylefly / wesight

A desktop AI agent workspace that supports Hermes Agent, Claude Code, Codex, and OpenClaw. It includes a runtime dashboard for tracking latency and token usage, and a live workspace for monitoring code writes and diffs.

xaspx / hermes-control-interface

This self-hosted web dashboard serves as a comprehensive control plane for managing MCP server lifecycles and ZOO Swarm agent health. It integrates a browser-based terminal and file explorer with real-time chat features, including streaming and tool call visualization.

jazzyalex / agent-sessions

A native macOS session browser and cockpit that tracks analytics and limits for Hermes alongside other coding-agent CLIs. It provides searchable transcript history, image browsing, and live per-session quota burn-rates for specific models.

nickvasilescu / hermes-desktop-os1

This native macOS workspace facilitates one-click automated Hermes Agent installation on Orgo cloud VMs and SSH hosts. It distinguishes itself with an integrated WebRTC voice mode powered by OpenAI Realtime and Orgo MCP.

liftaris / herm

Built with OpenTUI, this project provides a terminal-based interface and dashboard for managing Hermes profiles, skills, and cron jobs. It includes a dedicated kanban board for tracking agentic work and task management.

sharbelxyz / hermes-agent-mission-control

This self-hostable dashboard template uses a Postgres message bus to bridge local agents with a web-based mission control. It features a specialized approval inbox for managing agent requests that have side effects.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA designed for Telegram Mini App v2.0 that supports background agent spawning for up to five concurrent instances. It utilizes dual HMAC-SHA256 and Ed25519 authentication to validate Telegram sessions while providing a terminal chat with file attachments.

aivrar / portable-hermes-agent

This Windows desktop GUI requires no installation, Docker, or admin rights to run Hermes with local or cloud models. It features a dynamic tool maker for creating API and Python handlers and includes built-in support for ComfyUI and TTS.

pyrate-llama / hermes-ui

A glassmorphic web interface that provides real-time log streaming and a task tracking dashboard for the self-hosted assistant. Users can manage skills, cron jobs, and MCP servers through an integrated file browser and management suite.

sanchomuzax / hermes-webui

This monitoring dashboard focuses on process oversight by providing real-time session activity and cost tracking. It allows for full inspection of conversation histories and skill source code while offering read-only monitoring of environment variables.

Euraika-Labs / pan-ui

A chat-first workspace featuring tool approval cards and isolated profile management for separate memory and API keys. It includes an integrated marketplace for discovering and installing new skills and MCP servers.

Felix-Forever / hermes-agent-desktop

This desktop client enables orchestrated collaboration between 20 specialized AI agents managed by a PM orchestrator. It features a visual Skill Store with over 50 one-click installations and supports native streaming SSE responses.
