breakdown

farion1231 / cc-switch

A lightweight Tauri-based desktop manager that provides a unified control center for Hermes Agent alongside other major AI coding CLIs. It offers cross-platform support for Windows, macOS, and Linux, serving as a high-performance bridge for developers juggling multiple agentic tools.

iOfficeAI / AionUi

This local open-source app acts as a collaborative workspace for Hermes Agent and various CLI agents, featuring built-in tools for web searching and file writing. It uniquely automates the creation of editable office documents like PPT, Word, and Excel directly from agent outputs.

nesquena / hermes-webui

Designed for mobile and web accessibility, this interface maintains full feature parity with the Hermes CLI through a functional three-panel layout. It includes a dedicated workspace file browser and a context ring for real-time monitoring of token usage.

fathah / hermes-desktop

A comprehensive desktop companion that simplifies the lifecycle of Hermes Agent through guided installation and configuration workflows. It features an integrated GUI for managing sessions, profiles, and toolsets across both local and remote AI providers.

EKKOLearnAI / hermes-web-ui

This dashboard extends Hermes Agent into communication platforms by offering unified configuration for Telegram, Discord, Slack, and WhatsApp. It supports multi-profile isolation for models and memory, alongside detailed tool call inspection and markdown rendering.

outsourc-e / hermes-workspace

A native web workspace featuring a 'Swarm Mode' with role-based dispatch and tmux-backed workers for complex task handling. It integrates a Monaco-powered file browser, a PTY terminal, and a dedicated memory browser to manage the agent's long-term knowledge.

dodo-reach / hermes-desktop

A native macOS workspace tailored for power users, offering direct local or SSH connections to Hermes hosts with a real embedded terminal. It organizes agent activity through native views for Kanban boards, cron jobs, and system repair sessions.

xaspx / hermes-control-interface

This self-hosted dashboard provides a sophisticated control plane for managing MCP server lifecycles and agent health. It features a 'ZOO Swarm Monitor' for tracking kanban pipelines and real-time tool call visualization within a streaming chat interface.

Eynzof / hermes-agent-cn-desktop

A Windows-optimized desktop application built with Tauri and Rust that provides a localized experience for managing local and cloud model providers. It features an advanced UI specifically designed for monitoring complex tasks, skills, and agent memory.

jazzyalex / agent-sessions

A privacy-focused macOS session browser that indexes Hermes transcripts locally without telemetry or remote data uploads. It functions as an 'agent cockpit' with live quota monitoring and per-session burn-rate analytics to track API costs.

abundantbeing / hermes-browser-extension

A Chromium side-panel extension that bridges the active browser context with a local or remote Hermes runtime. It allows users to inject tab metadata and selected text into sessions for instant summarization or action-item extraction.

nickvasilescu / hermes-desktop-os1

This macOS workspace targets cloud-based workflows by providing one-click automated installation of Hermes Agent on Orgo cloud VMs and SSH hosts. It uniquely integrates a WebRTC voice mode using OpenAI Realtime and Orgo MCP for vocal interaction.

liftaris / herm

An alternative terminal-based dashboard built with OpenTUI that renders markdown, LaTeX, and tool calls within a keyboard-driven interface. It utilizes Kanban boards for diagnosing agentic work and provides TUI-based management for profiles and memory.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA designed to run as a Telegram Mini App, offering a terminal-style chat with file attachment support. It enables background agent spawning and real-time health monitoring directly from a mobile device.

aivrar / portable-hermes-agent

A zero-install, portable Windows solution that requires no admin rights or Docker to run Hermes Agent with over 100 pre-configured tools. It includes a workflow engine for multi-step automation and supports local models via LM Studio, TTS, and ComfyUI.

pyrate-llama / hermes-ui

A self-hosted web interface featuring a glassmorphic design for real-time log streaming and chat. It provides a centralized dashboard for tracking tasks, managing MCP servers, and browsing files within the agent's environment.

sanchomuzax / hermes-webui

A specialized monitoring dashboard that focuses on cost tracking and model distribution across Hermes sessions. It utilizes FTS5 for searchable conversation histories and provides read-only inspection of custom agent skills and configurations.

Euraika-Labs / pan-ui

A chat-first workspace that emphasizes security and discovery through tool approval cards and an integrated marketplace for MCP servers. It allows for isolated profile management, ensuring separate API keys and memory stores for different projects.

Felix-Forever / hermes-agent-desktop

A multi-agent desktop client that orchestrates collaboration between 20 specialized AI agents via a central PM orchestrator. It features a visual Skill Store for one-click installations and a native interface for streaming model responses.
