breakdown

farion1231 / cc-switch

This cross-platform manager, built on the Tauri 2 framework, provides a unified interface for Windows, macOS, and Linux users. It centralizes configuration management for Hermes Agent alongside other CLI tools like Claude Code and Gemini CLI.

iOfficeAI / AionUi

AionUi is a local cowork application that integrates external agents including Hermes Agent and Claude Code. It features built-in assistants for generating editable office documents and supports remote access through a WebUI or messaging platforms like Telegram.

nesquena / hermes-webui

This interface runs the Hermes agent in-process using existing configurations and models, accessible via browser or mobile through secure SSH tunneling. The layout includes a three-panel workspace with integrated file browsing for direct interaction.

fathah / hermes-desktop

This desktop companion app simplifies the initial experience with guided installation and provider setup for Hermes Agent. It provides a graphical interface for managing chat sessions, tools, and multiple AI providers.

EKKOLearnAI / hermes-studio

Hermes Studio serves as a local control plane for managing profiles, credentials, and scheduled jobs across ten platform channels like WhatsApp and Slack. It distinguishes itself with a visual node-based workflow builder and integrated usage analytics.

outsourc-e / hermes-workspace

This native web workspace features a Swarm Mode with role-based dispatch and tmux-backed workers for complex tasks. It integrates a Monaco-based file browser, a PTY terminal, and specialized managers for skills and MCP catalogs.

xintaofei / codeg

Codeg aggregates sessions from fifteen ACP-compatible agents, including Hermes, into a collaborative workspace available as a desktop app or Docker container. It supports unattended review by executing concurrent tasks within isolated git worktrees.

dodo-reach / hermes-desktop

Designed as a native Mac workspace, this tool offers direct local or SSH connections to Hermes hosts with an embedded terminal for system repair. It organizes agent activity through native views for Kanban boards, skills, and cron jobs.

Eynzof / Hermes-CN-Desktop

Built with Tauri, TypeScript, and Rust, this Windows-first application includes the Hermes-CN-Core kernel for local agent execution. The UI supports LaTeX and Mermaid rendering while providing dedicated management for MCP tools and memory.

abundantbeing / hermes-browser-extension

This Chromium extension connects a local or remote Hermes runtime to the active browser context via a side-panel. It includes an MV3 controller for approved tab actions and site-aware drafting capabilities across 31 writing environments.

uzairansaruzi / hermex

Hermex is a native SwiftUI app for iOS 18+ that pairs with a hermes-webui server to drive self-hosted agents from a phone. It allows users to manage sessions and skills while providing read-only access to agent memory and analytics.

freestylefly / wesight

This desktop workspace offers one-click setup for Hermes Agent and other engines with custom LLM model routing. It features a runtime dashboard for tracking latency and token usage alongside a live workspace for monitoring code diffs.

xaspx / hermes-control-interface

This self-hosted web dashboard provides a comprehensive control plane for managing MCP server lifecycles and monitoring agent health via the ZOO Swarm Monitor. It features a browser-based terminal, file explorer, and real-time chat with tool call visualization to oversee the entire Hermes AI agent stack.

jazzyalex / agent-sessions

A native macOS session browser that aggregates searchable history from fifteen different coding agent CLIs into a single cockpit. It prioritizes privacy through local operation without telemetry while tracking per-session quota burn for Codex and Claude models.

nickvasilescu / hermes-desktop-os1

This native macOS workspace facilitates one-click automated Hermes Agent installation on Orgo cloud VMs and SSH hosts. It distinguishes itself by integrating a WebRTC voice mode powered by OpenAI Realtime and Orgo MCP for hands-free interaction.

sharbelxyz / hermes-agent-mission-control

Built with Next.js 16 and React 19, this dashboard template uses a Postgres message bus to bridge local agents with a web-based interface. It includes a specialized approval inbox designed specifically for managing agent requests that have side effects.

liftaris / herm

This project offers a terminal-based alternative for managing Hermes Agent sessions using OpenTUI. It combines a TUI chat interface with a kanban board for task management, allowing users to handle profiles, skills, and cron jobs from the command line.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA designed for Telegram Mini App v2.0 that supports background agent spawning for up to five concurrent instances. It secures local operations using dual HMAC-SHA256 and Ed25519 authentication for Telegram validation.

aivrar / portable-hermes-agent

This Windows desktop solution requires no installation, Docker, or admin rights to provide a GUI for local and cloud AI models. It features a dynamic tool maker for API and Python handlers alongside built-in support for ComfyUI workflows and TTS.

pyrate-llama / hermes-ui

A glassmorphic web interface that provides real-time log streaming and a task tracking dashboard for self-hosted AI assistants. It includes dedicated management tools for organizing skills, cron jobs, and MCP servers within a visual environment.

sanchomuzax / hermes-webui

This monitoring-focused dashboard tracks session activity and costs in real-time while providing full inspection of conversation histories. It offers read-only visibility into environment variables and skill source code to ensure configuration oversight.

Euraika-Labs / pan-ui

A chat-first workspace that utilizes tool approval cards and SSE streaming to manage agent interactions. It features an integrated marketplace for discovering MCP servers and supports isolated profile management for separate memory and API keys.

Felix-Forever / hermes-agent-desktop

This desktop client coordinates collaboration between 20 specialized AI agents managed by a PM orchestrator. It includes a visual Skill Store with over 50 one-click installations and supports native model switching with streaming responses.
