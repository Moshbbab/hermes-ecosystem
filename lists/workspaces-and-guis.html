breakdown

farion1231 / cc-switch

This cross-platform manager, built on the Tauri 2 framework, provides a unified interface for configuring Hermes Agent alongside other CLIs like Claude Code and Gemini. It supports Windows, macOS, and Linux, serving as an all-in-one administrative tool for multiple agent environments.

iOfficeAI / AionUi

AionUi is a local cowork application featuring a built-in agent engine with full file read and write capabilities. It includes 21 professional assistants for document and presentation tasks and supports remote access through WebUI and messaging platforms like Telegram.

nesquena / hermes-webui

This web-based interface is built using Python and vanilla JavaScript to enable Hermes Agent access from browsers and mobile devices without a build step. It features a circular context ring for monitoring token usage and supports secure remote access via SSH tunnels.

fathah / hermes-desktop

This desktop companion simplifies the initial experience with Hermes Agent through guided installation and provider setup. It provides a graphical user interface for managing chat sessions, tools, and multiple AI providers in a single application.

EKKOLearnAI / hermes-studio

Hermes-studio is a web dashboard that features a visual workflow canvas with approval gates and loops for complex task automation. It manages local sessions via a self-built SQLite database and integrates with messaging channels including Telegram, Discord, Slack, and WhatsApp.

outsourc-e / hermes-workspace

This native web workspace includes a Monaco-based file browser, a PTY terminal, and a memory browser for deep agent inspection. It uniquely offers a Swarm Mode that utilizes role-based dispatching and tmux-backed workers for coordinated agent activity.

xintaofei / codeg

Codeg is a collaborative workspace that aggregates sessions from fifteen built-in agents, including Hermes and Claude Code, into a single interface. It supports desktop, Docker, and native mobile clients, and allows users to register any ACP-compatible agent.

dodo-reach / hermes-desktop

Designed as a native Mac workspace, this tool provides direct local or SSH connections to Hermes hosts with an embedded terminal for system repair. It features native views for managing Kanban boards, skills, and cron jobs directly from the desktop.

Eynzof / Hermes-CN-Desktop

This Windows-first desktop application is built with Tauri and Rust, featuring a specialized Hermes-CN-Core kernel with health check and update capabilities. It provides native window management and a UI capable of rendering LaTeX and Markdown for technical interactions.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension bridges active browser context with local or remote Hermes runtimes for site-aware drafting and tab management. It includes a Bot Mode for multi-agent switching and collaborative threading within the browser interface.

uzairansaruzi / hermex

Hermex is a native SwiftUI app for iOS 18+ that allows users to drive self-hosted Hermes agents directly from an iPhone. It pairs with a hermes-webui server to provide real-time chat, task management, and workspace file browsing without third-party relays.

freestylefly / wesight

Wesight is a desktop workspace offering one-click setup for Hermes Agent and custom LLM model routing. It includes a runtime dashboard for tracking latency and token usage, alongside a live workspace for monitoring code writes and diffs in real-time.

joeynyc / hermes-hud

This terminal-based consciousness monitor features an interactive TUI with nine tabs and four selectable color themes for tracking agent growth and git projects. It includes a tmux operator view specifically designed for managing live agent panes and scheduled cron jobs.

xaspx / hermes-control-interface

This self-hosted web dashboard provides a browser-based terminal, file explorer, and a ZOO Swarm Monitor for tracking agent health via kanban pipelines. It functions as an MCP server control plane that supports real-time chat with streaming and tool call visualization.

jazzyalex / agent-sessions

A native macOS session browser that indexes local agent transcripts across 14 formats, including Claude Code and Cursor, without uploading data. It serves as an analytics cockpit that tracks per-session burn against five-hour and weekly quota windows.

nickvasilescu / hermes-desktop-os1

This native macOS workspace facilitates one-click automated Hermes Agent installation on Orgo cloud VMs and SSH hosts. It features an integrated WebRTC voice mode utilizing OpenAI Realtime and Orgo MCP for remote agent interaction.

sharbelxyz / hermes-agent-mission-control

Built with Next.js 16 and React 19, this dashboard template uses a Postgres message bus to bridge local agents with a web-based interface. It includes a dedicated approval inbox for managing agent requests that trigger side effects.

liftaris / herm

Built with OpenTUI, this alternative interface provides a TUI for chatting and managing agent sessions alongside a kanban board for task management. Users can manage profiles, skills, cron jobs, and toolsets within a unified terminal environment.

clawvader-tech / hermes-telegram-miniapp

This mobile-first React SPA dashboard for Telegram Mini App v2.0 supports background agent spawning for up to five concurrent instances. It features terminal chat with streaming responses and secures Telegram validation via dual HMAC-SHA256 and Ed25519 authentication.

aivrar / portable-hermes-agent

This portable Windows desktop application runs via self-contained Python and Node.js environments without requiring Docker or admin rights. It includes 100 tools for TTS, music, and ComfyUI, supporting both local models via LM Studio and cloud models via OpenRouter.

pyrate-llama / hermes-ui

This glassmorphic web interface provides real-time log streaming and a task tracking dashboard for self-hosted AI assistants. It integrates a file browser with management tools for skills, cron jobs, and MCP servers.

sanchomuzax / hermes-webui

This monitoring dashboard focuses on session activity and cost tracking with full inspection capabilities for conversation histories and skill source code. It provides read-only access to configuration settings and environment variables for process oversight.

Euraika-Labs / pan-ui

A chat-first workspace featuring real-time SSE streaming and tool approval cards for secure execution. It includes an integrated marketplace for discovering skills and MCP servers, alongside isolated profile management for separate memory and API keys.

Felix-Forever / hermes-agent-desktop

This native desktop client orchestrates collaboration between 20 specialized AI agents through a central PM orchestrator. It features a Visual Skill Store with over 50 one-click installations and supports real-time model switching during streaming chat sessions.
