breakdown

farion1231 / cc-switch

This cross-platform manager provides a unified desktop interface for Hermes Agent alongside other major AI coding CLIs like Claude Code and Codex. Built with Tauri 2, it offers a lightweight solution for users who need to switch between multiple agent environments on Windows, macOS, or Linux.

iOfficeAI / AionUi

AionUi is a local cowork application that provides a unified GUI for Hermes Agent and other CLI-based agents, featuring built-in tools for web searching and file writing. It distinguishes itself by automating the creation of editable office documents, including PowerPoint, Word, and Excel files.

nesquena / hermes-webui

This web-based interface offers full feature parity with the Hermes CLI through a functional three-panel layout that includes a workspace file browser. It helps users manage context effectively by integrating a dedicated 'context ring' for real-time token usage monitoring.

fathah / hermes-desktop

Designed as a comprehensive desktop companion, this app simplifies the lifecycle of Hermes Agent through guided installation and configuration. It provides an integrated GUI for managing sessions and toolsets across various local and remote AI providers.

EKKOLearnAI / hermes-web-ui

This dashboard focuses on multi-platform connectivity, allowing users to configure Hermes Agent for use across Telegram, Discord, Slack, and WhatsApp. It supports isolated profiles for managing distinct models, skills, and file storage within a single web interface.

outsourc-e / hermes-workspace

This native web workspace features a 'Swarm Mode' with role-based dispatch and tmux-backed workers for complex task orchestration. It includes a full file browser powered by Monaco, a PTY terminal, and an integrated browser for managing memories and MCP catalogs.

dodo-reach / hermes-desktop

A native macOS workspace that provides direct shell access via an embedded terminal and supports both local and SSH connections to Hermes hosts. It organizes agent activity through native views for Kanban boards, skills management, and cron jobs.

xaspx / hermes-control-interface

This self-hosted dashboard acts as a control plane for the Hermes stack, featuring a ZOO Swarm Monitor to track agent health and Kanban pipelines. It provides real-time tool call visualization and a dedicated interface for managing the lifecycle of MCP servers.

Eynzof / hermes-agent-cn-desktop

Built with Tauri and Rust, this Windows-optimized desktop application provides a localized experience for managing local and cloud model providers. It features an advanced UI specifically designed for monitoring tasks, memory, and agent skills.

jazzyalex / agent-sessions

This macOS-native session browser focuses on analytics and history, offering a 'Quota Meter' to track usage limits across various coding agents. It ensures privacy by using local-only indexing for searching conversation histories without telemetry or remote logging.

nickvasilescu / hermes-desktop-os1

This macOS workspace is tailored for Orgo cloud computers, offering one-click automated installation of Hermes Agent on fresh cloud VMs. It uniquely supports a WebRTC voice mode, enabling verbal interaction with the agent via OpenAI Realtime and Orgo MCP.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension bridges the gap between the web and the agent by feeding active browser context directly into Hermes prompts. It connects to both local and remote API gateways, allowing the agent to 'see' the user's current web environment.

liftaris / herm

Built with OpenTUI, this terminal-based dashboard provides a keyboard-centric way to manage Hermes profiles, skills, and memory. It includes specialized rendering for LaTeX and markdown, alongside Kanban boards for diagnosing agentic workflows.

clawvader-tech / hermes-telegram-miniapp

This mobile-first React SPA functions as a Telegram Mini App, providing a terminal-style chat interface for Hermes on the go. It allows users to spawn background agents and monitor system health or cron jobs directly from their mobile device.

aivrar / portable-hermes-agent

This zero-install Windows solution requires no admin rights or Docker, making Hermes Agent fully portable. It comes pre-loaded with 100 tools, including local TTS and ComfyUI extensions, and features a workflow engine for multi-step automation.

pyrate-llama / hermes-ui

Featuring a modern glassmorphic design, this web interface provides real-time log streaming and task tracking for self-hosted Hermes instances. It serves as a centralized hub for managing MCP servers, cron jobs, and agent skills through a browser.

sanchomuzax / hermes-webui

This dashboard emphasizes process monitoring by providing a real-time activity feed that tracks costs and model distribution. It utilizes FTS5 for deep, searchable conversation history and offers read-only inspection of agent configuration and skills.

Euraika-Labs / pan-ui

Pan-ui is a chat-first workspace that uses SSE streaming and tool approval cards to give users granular control over agent actions. It features an integrated marketplace for discovering skills and MCP servers, alongside isolated profile management for separate API keys.

Felix-Forever / hermes-agent-desktop

This desktop client facilitates orchestrated collaboration between 20 specialized AI agents managed by a PM orchestrator. It includes a visual 'Skill Store' for one-click installations of over 50 curated capabilities.
