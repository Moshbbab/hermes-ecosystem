breakdown

farion1231 / cc-switch

This Tauri-based desktop manager provides a lightweight, cross-platform interface for managing Hermes Agent alongside other major CLI tools like Claude Code and Gemini. It serves as a unified hub for users who need to switch between multiple agent environments on Windows, macOS, or Linux.

iOfficeAI / AionUi

AionUi is a comprehensive local cowork application that pairs Hermes Agent with a powerful engine for web search, file access, and MCP tool integration. It distinguishes itself by automating the generation of editable office documents like PPT, Word, and Excel directly from agent workflows.

nesquena / hermes-webui

This lightweight Python and JavaScript web interface brings the full Hermes CLI experience to browsers and mobile devices. It features a functional three-panel layout that allows users to simultaneously manage chats, active sessions, and workspace files.

fathah / hermes-desktop

Designed as a dedicated companion app, this tool simplifies the setup process with guided installation and dependency resolution for Hermes Agent. It provides a unified GUI for managing session history and profiles while supporting 14 distinct toolsets including code execution.

EKKOLearnAI / hermes-web-ui

This dashboard focuses on multi-platform connectivity, allowing users to configure Hermes Agent for use across Telegram, Discord, Slack, and WhatsApp. It offers robust multi-profile support to isolate models, memory, and skills for different communication channels.

outsourc-e / hermes-workspace

This native web workspace introduces a 'Swarm Mode' with role-based dispatching and tmux-backed workers for complex task handling. It integrates a Monaco-based file browser, a PTY terminal, and a dedicated MCP catalog for advanced workspace management.

dodo-reach / hermes-desktop

A native macOS workspace that prioritizes system-level access through real SSH connections and embedded terminals for direct shell repair. It organizes agentic work through native views for Kanban boards, cron jobs, and session data.

xaspx / hermes-control-interface

This self-hosted dashboard acts as a control plane for managing the lifecycle of MCP servers and monitoring agent health via the ZOO Swarm Monitor. It provides real-time tool call visualization and a Kanban pipeline to track active agent tasks.

Eynzof / hermes-agent-cn-desktop

Built with Tauri and Rust, this Windows-first desktop application provides a localized experience for managing both local and cloud model providers. It features an advanced UI specifically for monitoring memory, skills, and real-time task execution.

abundantbeing / hermes-browser-extension

This Chromium side-panel extension bridges the gap between web browsing and AI by connecting active page context to a Hermes runtime. It enables quick commands like /summarize and /explain directly within Chrome, Edge, or other Chromium-based browsers.

jazzyalex / agent-sessions

This macOS session browser functions as a specialized cockpit for inspecting rich Markdown transcripts and collapsible tool calls. It stands out by providing live quota tracking and burn-rate analytics to monitor the costs of active agent sessions.

nickvasilescu / hermes-desktop-os1

This macOS workspace is tailored for Orgo cloud computers, offering one-click automated installation of Hermes Agent on fresh cloud VMs. It uniquely supports a WebRTC voice mode using OpenAI Realtime for vocal interaction with the agent.

liftaris / herm

Built on OpenTUI, this terminal-based dashboard provides a keyboard-centric way to manage Hermes profiles, skills, and memory. It includes integrated Kanban boards for diagnosing agentic work and renders complex outputs like LaTeX and tool calls within the TUI.

clawvader-tech / hermes-telegram-miniapp

This mobile-first React dashboard operates as a Telegram Mini App, offering terminal-style chat with vision-based file support. It includes real-time system monitoring for hardware metrics and can spawn up to five concurrent background agent instances.

aivrar / portable-hermes-agent

This no-install Windows solution requires no admin rights or Docker, making it the most accessible entry point for local Hermes deployment. It comes pre-loaded with 100 tools, including ComfyUI and music generation, and features a workflow engine for multi-step automation.

pyrate-llama / hermes-ui

Featuring a modern glassmorphic design, this web interface provides real-time log streaming and a task-tracking dashboard. It serves as a centralized management hub for skills, cron jobs, and MCP servers through a self-hosted environment.

sanchomuzax / hermes-webui

This dashboard focuses on process monitoring, using WebSocket-based updates to provide real-time activity tracking of the agent. It includes full-text search capabilities for inspecting conversation histories and visual tools for managing scheduled cron jobs.

Euraika-Labs / pan-ui

Pan-ui is a chat-first workspace that emphasizes security and control through tool approval cards and isolated profile management. It features an integrated marketplace for discovering and installing new skills and MCP servers to extend agent capabilities.

Felix-Forever / hermes-agent-desktop

This desktop client facilitates orchestrated collaboration between 20 specialized AI agents managed by a PM orchestrator. It includes a visual 'Skill Store' for one-click installations and supports streaming SSE responses for a responsive chat experience.
