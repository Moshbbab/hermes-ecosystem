breakdown

farion1231 / cc-switch

This cross-platform manager, built on the Tauri 2 framework, provides a unified interface for Windows, macOS, and Linux users. It centralizes configuration management for Hermes Agent alongside other CLI tools like Claude Code and Gemini CLI.

iOfficeAI / AionUi

AionUi functions as a local coworking application that supports both built-in and external agents, including Hermes Agent. It features 21 specialized assistants for document creation and enables remote interaction through a WebUI or messaging platforms like Telegram.

nesquena / hermes-webui

Developed with Python and vanilla JavaScript, this web interface allows users to access Hermes Agent from browsers or mobile devices without a build step. It includes a circular context ring for token monitoring and supports secure remote access via SSH tunnels.

fathah / hermes-desktop

This desktop companion simplifies the Hermes Agent experience through guided installation and provider setup. It provides a dedicated GUI for managing chat sessions, tools, and multiple AI providers in a single environment.

EKKOLearnAI / hermes-studio

Hermes Studio is a web dashboard that manages five agent runtimes with features like tool traces, file previews, and usage analytics. It allows users to build visual workflows with approval gates and configure unified settings for 10 platforms, including Discord and Slack.

outsourc-e / hermes-workspace

This native web workspace features a Swarm Mode with role-based dispatch and tmux-backed workers for complex tasks. It integrates a Monaco-based file browser, a PTY terminal, and dedicated panels for memory browsing and skill management.

xintaofei / codeg

Codeg is a collaborative workspace that aggregates agent sessions into a desktop app, standalone server, or Docker container. It supports custom ACP-compatible agent registration and offers native iOS and Android clients for remote mobile access.

dodo-reach / hermes-desktop

Designed as a native Mac workspace, this tool provides direct local or SSH connections to Hermes hosts. It features an embedded terminal for system repair and native views for managing Kanban boards, skills, and cron jobs.

Eynzof / Hermes-CN-Desktop

Built with Tauri, TypeScript, and Rust, this Windows-first desktop application includes a built-in kernel for local agent execution. The interface supports LaTeX and Mermaid rendering while providing dedicated UI components for MCP tools and memory management.

abundantbeing / hermes-browser-extension

This Chromium extension integrates Hermes Agent into a browser side panel for site-aware drafting across 31 writing environments. It enables live browser control with explicit approval gates to ensure user oversight of agent actions.

uzairansaruzi / hermex

Hermex is a native SwiftUI app for iOS 18+ that allows users to drive a self-hosted Hermes Agent from an iPhone. It pairs with a hermes-webui server to manage tasks and skills while providing read-only access to agent memory.

freestylefly / wesight

Wesight offers a one-click setup for Hermes Agent and other engines, featuring a runtime dashboard to track latency and token usage. The workspace includes a live monitor for observing code writes and diffs in real-time.

xaspx / hermes-control-interface

A self-hosted web dashboard featuring a browser-based terminal, file explorer, and system metrics. It includes an MCP server control plane for lifecycle management and a ZOO Swarm Monitor to track agent health and kanban pipelines.

jazzyalex / agent-sessions

A native macOS session browser and cockpit that aggregates searchable transcripts and image previews from 14 agent sources. It operates locally without telemetry and tracks per-session quota burn for Claude and Codex models.

nickvasilescu / hermes-desktop-os1

A native macOS workspace designed for Hermes Agent instances running on SSH hosts and Orgo cloud computers. It provides one-click automated installation on fresh cloud VMs and integrated WebRTC voice mode via Orgo MCP and OpenAI Realtime.

sharbelxyz / hermes-agent-mission-control

A self-hostable dashboard template that uses a Postgres message bus to bridge local agents with a web interface. It features an approval inbox for requests with side effects and is built with Next.js 16 and React 19.

liftaris / herm

An alternative TUI and dashboard built with OpenTUI for chatting and managing Hermes Agent sessions. It includes a kanban board for task management and tools for managing profiles, skills, and cron jobs.

clawvader-tech / hermes-telegram-miniapp

A mobile-first React SPA dashboard designed for Telegram Mini App v2.0 that runs locally. It supports background agent spawning for up to five concurrent instances and uses HMAC-SHA256 and Ed25519 authentication.

aivrar / portable-hermes-agent

A portable Windows desktop version of Hermes Agent that requires no installation, Docker, or admin rights. It supports local models via LM Studio and includes a dynamic tool maker for Python and API handlers.

pyrate-llama / hermes-ui

A self-hosted glassmorphic web interface providing real-time log streaming and chat. It integrates a file browser, task tracking dashboard, and management tools for MCP servers, skills, and cron jobs.

sanchomuzax / hermes-webui

A process monitoring and configuration dashboard for real-time session activity and cost tracking. It allows for the inspection of skill source code, conversation histories, and read-only monitoring of environment variables.

Euraika-Labs / pan-ui

A self-hosted AI workspace featuring a chat-first interface with tool approval cards and SSE streaming. It includes an integrated marketplace for MCP servers and skills, alongside isolated profile management for API keys and memory.

Felix-Forever / hermes-agent-desktop

A native desktop client that orchestrates collaboration between 20 specialized AI agents. It features a Visual Skill Store with over 50 one-click installations and supports model switching with streaming SSE responses.
