breakdown

TauricResearch / TradingAgents

This framework organizes specialized agents into a multi-tier structure of researchers, traders, and portfolio managers for financial analysis. It enables backtesting across various LLM providers and data vendors to evaluate fundamental, sentiment, and technical trading strategies.

builderz-labs / mission-control

This self-hosted orchestration platform governs agent registration, task dispatching, and cost tracking through a centralized Web UI or CLI. It supports multi-agent workflows with integrated memory browsing and can be deployed locally via Node.js or Docker.

agent-of-empires / agent-of-empires

This control surface manages multiple coding agents, including Hermes Agent, using tmux for persistent background execution and Docker for sandboxed environments. Users can monitor agent activity and review code diffs through both TUI and web-based dashboards.

CryptoDmitry / hermes-agent-control-room

This execution engine is the first to manage Hermes agents on the Solana blockchain while supporting the Claude-style MCP protocol in stdio mode. It features specialized detection for HTTP signals to handle payment-required states for paid API services.

shannhk / hermes-agent-control-room

Utilizing a level-based architecture, this template scales Hermes Agent from single VPS instances to automated teams using a task bus pattern for delegation. It includes bundled skills for infrastructure tasks such as security auditing, VPS provisioning, and backup management.

swarmclawai / swarmclaw

This framework facilitates the creation of autonomous agent swarms with durable memory and support for over 23 LLM providers. It features visual org charts to manage agent team delegation and integrates with MCP tools for expanded capabilities.

agent37-platform / minions

This mission control interface provides a Kanban board and live streaming of agent reasoning to supervise autonomous Hermes Agent tasks. It emphasizes human-in-the-loop verification, requiring manual approval for all agent-proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This system employs a strict pipeline architecture to coordinate 17 specialized agents across research, planning, and infrastructure domains. A Master Orchestrator manages the routing and coordination of these agents to ensure structured task execution.

linke-ai / hermes-agent-team

This local collaboration system orchestrates Leader and Specialist agents using Hermes Agent profiles and a real-time Web UI. It integrates MCP and ACP protocols to handle local tools and communication throughout the automated task lifecycle.

howdymary / hermes-agent-metaharness

This meta-harness automates the outer-loop optimization of benchmark code for Hermes Agent, referencing Arxiv research for its methodology. It orchestrates TBLite and TerminalBench-2 evaluations while tracking candidate mutations and frontier progress.

runtimenoteslabs / gladiator

This arena orchestrates nine autonomous agents across two competing AI companies to track performance metrics and GitHub star growth. It utilizes Hermes Agent for task execution and provides a real-time dashboard to visualize code and scoreboard data.

InfiniteWhispers / HermesAgent-MultiModel

Optimized for consumer GPUs, this fully-local framework implements a Mixture-of-Agents stack using Hermes for task routing and tool-calling. It eliminates cloud dependencies by running parallel model querying and synthesis via Ollama.
