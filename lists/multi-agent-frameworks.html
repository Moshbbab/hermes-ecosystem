breakdown

TauricResearch / TradingAgents

This framework focuses on financial trading by coordinating specialized agents for sentiment, technical, and fundamental analysis. It supports multiple LLM providers like OpenAI and Anthropic, utilizing a Portfolio Manager to oversee final transaction approvals and execution.

builderz-labs / mission-control

Mission Control provides a self-hosted orchestration layer for governing agent registration, memory browsing, and cost tracking across multi-agent workflows. It offers flexible access through Web UI, CLI, and REST API interfaces with support for local Node.js or Docker deployments.

agent-of-empires / agent-of-empires

This control surface manages parallel coding agent sessions, including Hermes Agent and Claude Code, using tmux for session persistence. It ensures secure execution by providing sandboxing through Docker, Podman, and Apple Container environments.

CryptoDmitry / hermes-agent-control-room

This project serves as an MCP agent execution engine on the Solana blockchain, supporting Claude-style MCP protocols in stdio mode. It includes specialized detection for HTTP signals to manage payment-required states for paid API services.

shannhk / hermes-agent-control-room

Utilizing a level-based architecture, this template scales Hermes Agent from single VPS instances to automated teams using a task bus pattern for delegation. It includes bundled skills specifically for VPS provisioning, security auditing, and backup management.

swarmclawai / swarmclaw

Swarmclaw enables the creation of autonomous agent swarms with support for over 23 LLM providers and durable agent memory. It features visual org charts to help users manage agent team delegation and integrates MCP tools for expanded capabilities.

agent37-platform / minions

This mission control interface allows users to supervise autonomous Hermes Agent work through a Kanban board and live reasoning streams. It emphasizes human-in-the-loop verification by requiring manual approval for all agent-proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This project coordinates 17 specialized agents across a strict pipeline architecture for research, planning, and infrastructure tasks. A Master Orchestrator manages the system to ensure precise routing and coordination between the specialized units.

linke-ai / hermes-agent-team

This local web system orchestrates Leader and Specialist agents using MCP and ACP protocols for tool and communication handling. It provides a real-time UI for monitoring agent dialogues and managing task lifecycles via a Hermes Kanban interface.

howdymary / hermes-agent-metaharness

This meta-harness automates the outer-loop optimization of benchmark harness code for Hermes Agent. It orchestrates TBLite and TerminalBench-2 evaluations while providing structured candidate mutation and frontier tracking.

runtimenoteslabs / gladiator

Gladiator creates an agent-vs-agent arena where two autonomous AI companies compete for GitHub stars using Hermes Agent for task execution. A real-time dashboard visualizes the competition, displaying agent tasks, code, and live scoreboard metrics.

InfiniteWhispers / HermesAgent-MultiModel

This fully-local framework implements a Mixture-of-Agents stack optimized for consumer GPUs like the RTX 4080 and 5080. It utilizes Hermes for task routing and tool-calling while performing parallel model querying and synthesis via Ollama.
