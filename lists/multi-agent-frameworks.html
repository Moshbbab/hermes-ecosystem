breakdown

builderz-labs / mission-control

This self-hosted orchestration dashboard provides a zero-dependency environment for dispatching tasks across multiple frameworks like CrewAI and LangGraph. It distinguishes itself through integrated security auditing, featuring secret detection and trust scoring to ensure safe multi-agent workflows.

agent-of-empires / agent-of-empires

This project offers a unified TUI and web control surface for managing diverse coding agents, including Hermes and Claude Code, across multi-repo workspaces. It emphasizes secure execution by sandboxing agents within Docker, Podman, or Apple Containers while supporting parallel git worktree operations.

CryptoDmitry / hermes-agent-control-room

Designed for scaling from single VPS instances to automated teams, this template utilizes a task bus pattern for efficient orchestrator-to-specialist delegation. It includes specialized skills for registry management and security auditing to maintain robust infrastructure for Hermes-based workflows.

shannhk / hermes-agent-control-room

This framework implements a level-based architecture to transition Hermes agents from individual tasks to complex team handoffs. It focuses on operational reliability by bundling skills for VPS provisioning, automated backups, and structured task delegation.

swarmclawai / swarmclaw

Swarmclaw enables the creation of autonomous agent swarms with durable memory and support for over 23 LLM providers. It stands out by providing a visual organizational chart to monitor agent team hierarchies and real-time activity.

Agent-3-7 / minions

Acting as a mission control center, this tool uses a Kanban-style interface to supervise autonomous Hermes agents and review their reasoning live. It prioritizes human-in-the-loop verification, requiring manual approval for all agent-proposed task completions.

1ilkhamov / opencode-hermes-multiagent

This system coordinates 17 specialized agents through a master orchestrator to handle everything from research to infrastructure. It enforces a strict development pipeline with mandatory reviewer and tester gates to ensure high-quality code refactoring and bug fixes.

linke-ai / hermes-agent-team

This local collaboration system uses MCP and ACP protocols to manage the lifecycle of Leader and Specialist agents. It features a real-time Web UI that integrates Hermes Kanban flows with live dialogue monitoring for transparent team coordination.

howdymary / hermes-agent-metaharness

Focused on meta-optimization, this project uses an automated outer-loop search to refine agent harness code based on academic research. It orchestrates benchmark evaluations via Hermes, tracking performance frontiers through structured candidate mutation and comparison.

runtimenoteslabs / gladiator

Gladiator creates an autonomous arena where two AI companies, powered by Hermes and Paperclip, compete for GitHub stars. The platform features a real-time scoreboard and dashboard to visualize the tasks, code, and learning progress of nine competing agents.

Rainhoole / hermes-agent-acp-skill

This utility implements ACP-style delegation to route tasks between Hermes subagents, Codex, and Claude Code. It is specifically designed to prevent parent context pollution through isolated workflows while enforcing safety via configurable timeouts and output limits.
