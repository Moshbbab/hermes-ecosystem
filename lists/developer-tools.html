breakdown

colbymchenry / codegraph

A local pre-indexed symbol knowledge graph that provides surgical context to reduce token usage and tool calls. It supports automatic synchronization as files change, ensuring Hermes Agent always has an up-to-date map of the codebase.

junhoyeo / tokscale

A high-performance Rust-based TUI and dashboard for tracking token usage and costs. It provides a centralized way to monitor expenditures across multiple platforms, including Hermes and Claude Code.

liaohch3 / claude-tap

A local trace viewer used to inspect API traffic, system prompts, and tool schemas. It allows developers to debug Hermes Agent by comparing adjacent requests using structured diffs.

bergside / typeui

An AI-driven UI builder that provides design systems and layout guidance via MCP servers and plugins. It integrates with any AI provider supporting markdown to streamline the generation of professional interfaces.

Salomondiei08 / oh-my-hermes

An opinionated workflow layer that orchestrates autonomous CTO loops for issue triage and PR management. It extends Hermes Agent with 23 specialized skills and integrates with Slack, Discord, and Telegram for plain-language control.

joeynyc / hermes-skins

A collection of customizable YAML themes and ASCII art for the Hermes terminal UI. It allows users to personalize their visual presentation through a library of pre-made aesthetics and inheritance-based overrides.

tinyhumansai / tiny.place

A social economy for autonomous agents featuring encrypted messaging via the Signal Protocol. It enables agent identity registration with @handles and facilitates commerce using Solana-based USDC and SOL payments.

AlexAI-MCP / hermes-CCC

A port of the Hermes Agent brain and 46 core skills directly into the Claude Code Channel. It eliminates the need for OAuth or external processes while adding MLOps tools for vLLM and RL training.

unmodeled-tyler / vessel-browser

An AI-native browser designed for autonomous agent control via MCP. It provides real-time visual supervision of agent actions and uses de-structured bookmarks to provide necessary context to AI providers.

Abruptive / Ankh.md

A TAW Agent framework that enables the creation of scoped Hermes Agents with per-folder configurations. It allows for seamless switching between default and project-local memories, tools, and instructions.

adityahimaone / hermes-agent-rtk-caveman

A preconfigured setup utilizing RTK and Caveman templating to achieve 90-99% token savings. It includes over 40 specialized skills for finance and DevOps with automated installation for macOS and Linux.

roli-lpci / lintlang

A deterministic static linter that scans agent configs and system prompts for common failure modes without making LLM calls. It uses seven structural detectors to provide HERM v1.1 scoring across JSON, YAML, and .prompt files.

42-evey / evey-setup

An automated installation suite that deploys a Hermes Agent stack and 12+ supporting services in minutes. It offers three scalable deployment tiers and includes 29 community plugins across six functional categories.

0xNyk / openclaw-to-hermes

A migration utility that transfers personas, memories, and skills from OpenClaw to Hermes Agent. It maps complex model configurations to Hermes YAML format and handles the transfer of system-level credentials.

observeco / observeco

A cloud-independent observability tool providing real-time telemetry and self-healing auto-recovery for failed agents. It integrates with Hermes Agent via a plugin to track token drift, cost estimation, and memory bloat.
