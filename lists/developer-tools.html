breakdown

colbymchenry / codegraph

Codegraph builds a full project graph with `codegraph init`, using structural extraction and cross-file resolution for supported languages. Its MCP support lets Hermes Agent and other coding agents use pre-indexed code knowledge, with the stated aim of reducing token usage and tool calls.

junhoyeo / tokscale

Tokscale is a CLI for tracking token consumption and costs across Hermes and other AI coding agents. Its views cover sessions, models, daily summaries, and stats, and it can submit usage data to a leaderboard or create a public profile.

liaohch3 / claude-tap

Claude-tap records coding-agent API traffic and provides a self-contained HTML viewer for exported trace sessions. It supports tools including Hermes Agent, Claude Code, Codex, Gemini CLI, and Cursor CLI, and redacts common authentication headers before recording.

Javis603 / token-monitor

Token-monitor tracks token usage, costs, and rate limits across 46+ AI coding tools, including Hermes Agent. It also shows historical trends and usage breakdowns, with multi-device sync for viewing data across devices.

bergside / typeui

Typeui provides design systems and layout guidance through MCP servers to help build UI with AI. It is compatible with any AI provider that supports markdown or general prompting and integrates with Hermes Agent, Cursor, Claude, and GitHub Copilot.

Salomondiei08 / oh-my-hermes

Oh My Hermes adds an opinionated workflow layer for building, shipping, and operating apps with Hermes Agent. It includes skills for product briefs, design handoffs, and implementation, plus seven agents for roles across the product lifecycle and GitHub integration for issue and pull request delivery.

joeynyc / hermes-skins

Hermes-skins is a community CLI for customizing the Hermes terminal UI with banner colors, spinners, and ASCII art. YAML-based configuration supports theme creation, with options including retro DOS and cyberpunk aesthetics.

hermes-labs-ai / lintlang

Lintlang is a command-line static linter for AI agent configurations, tool descriptions, and system prompts, with HERM v1.1 scoring. It scans prompts, tool definitions, schemas, and agent files, then reports findings with specific fixes and supported line references.

tinyhumansai / tiny.place

Tiny.place provides encrypted agent-to-agent messaging using the Signal Protocol and identity registration with human-readable @handles. It also facilitates commerce through Solana-based USDC and SOL payments.

unmodeled-tyler / vessel-browser

Vessel-browser is an AI-native browser for autonomous agent control via MCP, with support for Anthropic, OpenAI, Ollama, and other AI providers. Its supervisor sidebar manages agent approvals, checkpoints, and conversation threads, and it supports external MCP clients and browser automation workflows.

AlexAI-MCP / hermes-CCC

Hermes-CCC ports Hermes Agent’s brain and 46 core skills to Claude Code Channel, where it runs natively without separate processes or OAuth. It also includes MLOps tools for vLLM, GGUF inference, and RL training.

topoteretes / cognee-integrations

Cognee-integrations is a monorepo of Cognee-owned integration packages with two tiers: a permanent knowledge graph and a session cache. Its Claude Code plugin auto-captures and auto-recalls context.

adityahimaone / hermes-agent-rtk-caveman

This setup combines RTK and Caveman templating for workflows described as achieving 90–99% token savings. It also includes 40+ preconfigured skills for finance, DevOps, and research, with automated installation for macOS and Linux.

Abruptive / Ankh.md

Ankh.md provides per-folder scoping for Hermes Agents, with local configuration and skills. It can switch between default and scoped agents and supports project-local memories, tools, and custom instructions.

42-evey / evey-setup

This project automates installation of hermes-agent and 12+ supporting services, with three deployment tiers ranging from a minimum viable setup to a production stack. It also supports 29 community plugins across six functional categories.

0xNyk / openclaw-to-hermes

This tool migrates OpenClaw data—including SOUL.md, MEMORY.md, skills, and memory archives—to Hermes. It also maps configurations and credentials to Hermes YAML and JSON formats and sets up systemd gateway services.

observeco / observeco

Observeco monitors AI agents with passive analysis or scheduled active probing, and can automatically recover multi-agent systems. Its native Hermes plugin exports real-time conversation telemetry and uses local file changes to help detect performance drift.

handnewb / hermes-voice

Hermes Voice adds voice interaction with wake-word support, adaptive turn-taking, and barge-in capabilities. It runs offline without API keys or accounts and supports 35 languages via Piper and 9 via Kokoro.

33hodl / hermes-startup

Hermes Startup is a local runtime for pursuing online opportunities, operating with zero network access by default. It requires explicit approval for consequential actions and external writes, and includes contracts for opportunities, offer previews, and exact approvals.

181079342 / hermes-memoss

Hermes Memoss is a memory plugin with semantic search and multi-dimensional memory storage. It provides tools to search, add, and delete memories, and includes a circuit breaker for MemOS API outages.
