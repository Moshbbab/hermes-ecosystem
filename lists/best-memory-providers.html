For the architecture behind these tools, read The Hermes Agent Memory Guidebook.

breakdown

mem0ai / mem0

This universal memory layer provides multi-level storage for user, session, and agent states using temporal reasoning and multi-signal retrieval. It is available as an Apache-2.0 self-hosted server, an OSS SDK, or a managed cloud service.

volcengine / OpenViking

This context database organizes information as a virtual filesystem using viking:// URIs and a tiered L0/L1/L2 loading system. It achieved a 91% token reduction and significant task-completion gains on LoCoMo10 while providing observable retrieval trajectories for debugging.

topoteretes / cognee

Cognee is a self-hosted knowledge graph engine designed to give agents persistent long-term memory across multiple sessions. It supports unified ingestion and multimodal data search through Python, Rust, and TypeScript clients.

garrytan / gbrain

This opinionated agent brain generates cited prose answers and performs explicit gap analysis to identify missing information. It builds knowledge graphs using typed edges without LLM calls and ensures data isolation through scoped institutional memory.

supermemoryai / supermemory

This engine features a custom vector graph engine and byte-level deduplication to support sub-300ms recall at scales exceeding 100B tokens per month. It automates fact extraction and user profiling using connectors for platforms like Google Drive, Notion, and GitHub.

vectorize-io / hindsight

Hindsight implements long-term retain, recall, and reflect workflows to help agents learn over time. The system supports over 25 LLM providers and offers deployment flexibility via Docker, Kubernetes, or managed cloud environments.

plastic-labs / honcho

This library serves as the core logic for building stateful agents and acts as the upstream dependency for the honcho-self-hosted wrapper. It provides FastAPI-based service logic and SDKs for managing sessions and peer relationships.

campfirein / byterover-cli

This system manages memory as a git-like repository, utilizing a 5-tier retrieval process where four tiers are non-LLM based for sub-100ms performance. It features an interactive TUI and supports version control operations like branching and merging over a markdown context tree.

mnemosyne-oss / mnemosyne

Mnemosyne is a zero-dependency, sub-millisecond memory system that utilizes a single SQLite database for local storage. It integrates with Hermes via MCP, a Python SDK, or OpenWebUI and requires only Python 3.10 or higher.

ClaudioDrews / memory-os

This seven-layer memory system utilizes Qdrant, Redis, and SQLite to manage structured facts and an auto-curated wiki. It employs a Ground Truth hierarchy to ensure agents prioritize specifically injected context during recall.

greyhaven-ai / autocontext

This recursive harness produces filesystem-first artifacts, such as playbooks and context bundles, to improve agent performance on complex tasks. It features outcome-gated promotion and ablation-backed attribution to validate changes to the agent's context.

stephenschoettler / hermes-lcm

This plugin provides lossless context management by using a hierarchical DAG and SQLite store to ensure no messages are lost. It includes specialized recall tools like lcm_grep and lcm_recall to help agents recover specific details from their history.

vshulcz / deja-vu

This tool indexes existing local session history from over 20 coding agents to enable millisecond lookups across months of past data. It prioritizes security by redacting keys and tokens during the indexing process of gigabytes of historical data.

elkimek / honcho-self-hosted

Honcho provides a self-hosted backend for private cross-session memory that supports any OpenAI-compatible LLM or local inference server. It includes an automated setup script for Docker, PostgreSQL, and Redis to facilitate deployment for Hermes Agent.

Signet-AI / signetai

Signet-AI maintains a living semantic ontology through a background process called dreaming to provide a local-first identity and memory layer. It supports real-time ingestion from Obsidian, Discord, and GitHub while integrating with harnesses like Hermes Agent and Gemini CLI.

plur-ai / plur

This shared memory layer stores data as human-readable YAML files on local disk using an open engram format. It retrieves information through a hybrid search combining BM25 and local embeddings, integrating directly with MCP tools.

yoloshii / ClawMem

ClawMem is an on-device context engine that operates locally without API keys or cloud dependencies. It utilizes hybrid retrieval, including BM25 and vector search, and integrates via MCP, plugins, and Claude Code hooks.

EfficientContext / ContextPilot

ContextPilot optimizes long-context inference by reordering and deduplicating blocks to enable prefix reuse. This approach reduces prefill latency by 1.5–3× and saves up to 36% of tokens within the Hermes Agent and OpenClaw ecosystems.

Sibyl-Labs / Sibyl-Memory

Sibyl-Memory is a file-based long-term memory system that uses SQLite with FTS5 search instead of vector databases or embeddings. It is delivered as a five-package plugin family that includes an SDK, CLI, and a dedicated Hermes adapter.

yantrikos / yantrikdb-hermes-plugin

This self-maintaining plugin provides explainable recall by attaching a 'why_retrieved' tag to every result and includes a loop to resolve knowledge gaps. It supports owner-scoping for multi-user environments and features contradiction tracking and recency ranking.

ccf / agentcairn

AgentCairn uses an Obsidian vault as the source of truth, storing memory as inspectable Markdown files rather than opaque databases. It runs locally without a daemon or telemetry, utilizing DuckDB as a replaceable retrieval cache.

yepyhun / Brainstack

Brainstack acts as a memory kernel stack that integrates Hindsight, Graphiti, and MemPalace into a single owner. It manages state and retrieval using SQLite, Kuzu, and Chroma to provide agents with purpose-built evidence packets per query.

amanning3390 / flowstate-qmd

This anticipatory memory system prefetches context by watching agent session logs and storing data locally via SQLite-vec. It is an MCP-native server that uses GGUF models to provide RAG and vector search capabilities.

Perseus-Computing-LLC / perseus

Perseus resolves live workspace state into verified facts before the context window opens, resulting in up to 94% fewer prompt tokens. It employs a local-first architecture using SQLite and FTS5 and supports the Model Context Protocol (MCP) via stdio and SSE.

generalbusiness-ai / keep

This provider offers reflective memory through semantic search that combines BM25 full-text indexing with ranked graph traversal. It automates indexing for codebases and multimedia via OCR, using edge tags to establish navigable, bidirectional relationships between stored notes.

alias8818 / hermes-tool-slimmer

Designed to minimize prompt token overhead, this tool uses local BM25 ranking to select relevant tool schemas for Hermes Agent v0.14.0. It includes a dedicated dashboard for monitoring estimated schema token savings and supports native tool search functionality.

Ladybug-Memory / hermes-memory-plugin

This local-only plugin utilizes a columnar .lbdb embedded graph database to store memories with a built-in 1-10 importance ranking. It prioritizes high-value information during context prefetch using BM25-first retrieval and optional GLiNER2 entity extraction.

conorbronsdon / claude-context-os

A Git-backed workflow layer that stores identity, decisions, and workflows in plain Markdown files for coding agents like Claude Code and Codex. It facilitates source-neutral migrations for chats and documents, serving as a structured context layer for development tasks.

MukundaKatta / hermes-agentmemory

This episodic memory plugin features a pull-model with an on-demand summarizer and a trace.jsonl audit log for tracking all prefetch operations. It addresses persistent recall issues by supporting real, immediate event deletion to ensure removed data does not influence future responses.

piprail / piprail

This SDK and MCP server enables agents to handle financial transactions across 29 chains, including EVM and Solana, with 0% transaction fees. It allows Hermes agents to pay for services or charge for API access directly through integrated wallet settlements.

stepanov1975 / hermes-local-knowledge

This plugin indexes local skills, scripts, and MCP server configurations to improve agent routing through artifact search and graph neighbor traversal. It utilizes both implicit and explicit feedback to refine routing hints for local capability discovery.

yonro / hermes-xmemo-plugin

Providing durable cross-session memory, this plugin features pre-turn context injection and session-end snapshots for state persistence. It relies on a local SQLite reliability layer and a write outbox to manage searching, remembering, and updating agent state.

futurebrowser / hermes-exabase-plugin

This plugin integrates Exabase M-1 to provide self-organizing long-term memory for Hermes agents. It supports configurable query expansion and result reranking to optimize the retrieval of manually stored or searched memories.

visorcraft / MongrelDB-Hermes

An AI-native memory solution that secures data with AES-256-GCM encryption at rest and offers retrieval via HNSW ANN, sparse, and FM-index methods. It can be deployed through native Rust FFI or an HTTP daemon and includes MinHash deduplication and metadata filters.

sourcevault-ai / sourcevault-code-tools

This plugin provides private local code memory by adding deterministic slash commands for searching, syncing, and reading repository files. It requires a local SourceVault server to handle indexing and vector storage for grounded Q&A and structured tool use.

penfieldlabs / hermes-penfield

This provider features 17 tools for memory management and knowledge graph traversal using a hybrid search method that combines BM25, vector, and graph techniques. It also performs automatic context checkpointing during message compression to maintain continuity.

conorbronsdon / agent-memory-kit

This tool provides a file-based curation loop for agent memory that uses a git-backed directory to manage versioned, diffable markdown files. It features 'rot' and 'lint' curators to identify stale or conflicting data and includes five slash commands for capture, recall, and curation.
