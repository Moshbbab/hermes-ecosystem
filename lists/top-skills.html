breakdown

obra / superpowers

This framework implements a subagent-driven methodology to execute engineering tasks autonomously through a structured workflow of brainstorming, planning, and test-driven development. It functions as a plugin for various coding agents and CLI tools to enforce rigorous software development standards.

nexu-io / open-design

A local-first design and prototyping system that provides CLI support for 26 executables, including Hermes Agent and Claude Code. It allows agents to iterate on live designs via sandboxed iframe previews and export finished artifacts to formats like HTML, PDF, and MP4.

mukul975 / Anthropic-Cybersecurity-Skills

This library provides 818 structured security skills mapped to industry frameworks such as MITRE ATT&CK, NIST CSF 2.0, and the NIST AI RMF. It is compatible with over 26 AI platforms, offering a standardized foundation for cybersecurity operations.

topoteretes / cognee

Cognee serves as a self-hosted knowledge graph engine that grants agents persistent long-term memory across different sessions. By combining vector embeddings with graph-based reasoning, it enables complex search capabilities through Python, Rust, and TypeScript clients.

Agents365-ai / drawio-skill

This skill enables agents to generate editable .drawio files from natural language descriptions using 11 different diagram presets. It includes built-in self-check and auto-fix capabilities and can convert Mermaid text directly into diagram formats.

internet-court / internet-court-skill

Acting as a trust layer for agent-to-agent commerce, this project provides a master router for delegated permissions, escrow, and x402 payments. It integrates a verification and dispute resolution layer to facilitate secure transactions between autonomous entities.

conorbronsdon / avoid-ai-writing

This tool audits and rewrites content to eliminate detectable AI patterns using a two-pass detection system. It supports rewrite and edit-in-place modes with optional voice profiles for casual, professional, or technical tones.

AMAP-ML / SkillClaw

SkillClaw enables the collective evolution of agent capabilities by supporting skill merging and cross-pollination across platforms like Hermes and QwenPaw. It features a bilingual dashboard for inspecting session traces and managing the growth of the skill library.

wondelai / skills

A cross-platform library featuring 51 expert frameworks and 14 guided metaskills compatible with the agent-plugins.org specification. It maintains session state within a project's local directory to ensure continuity across agent interactions.

mohitagw15856 / pm-claude-skills

This collection contains 1,153 markdown-based skills designed for professional and life tasks that run natively in Hermes Agent and Claude Code. It includes ready-to-paste exports and specific integrations for tools like Slack, Raycast, and Obsidian.

ZeroPointRepo / youtube-skills

This plugin grants agents the ability to search YouTube, browse channels, and extract transcripts or playlist data. It is compatible with Hermes Agent, Cursor, and Windsurf, requiring a TranscriptAPI key for operation.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that monitors active workflows to automatically detect and propose new, reusable skills. It generates both SKILL.md documentation and Python scaffolds, allowing users to manage detected patterns via slash commands.

Cranot / super-hermes

This project enables Hermes Agent to generate custom analytical instructions and domain-specific thinking lenses for complex tasks. It enhances transparency by reporting findings alongside an assessment of potential analysis blind spots.

DougTrajano / pydantic-ai-skills

This toolkit provides modular packages for Pydantic AI that support instructions, resources, and scripts through a remote registry. It utilizes progressive disclosure to maintain prompt efficiency while offering type-safe support for programmatic skills.

AkoliteZA / hermes-agent-idea-workflow

This skill automates the transition from rough concepts to structured design and implementation documents. It features a spec review gate with PASS/FAIL evaluation models and offers Lite and Full modes to accommodate varying project complexities.

tlehman / litprog-skill

This skill implements literate programming by weaving prose, diagrams, and source code into unified documents. It includes a tangler to extract runnable files and automatically synchronizes source code edits back to the original documentation.

ReinaMacCredy / maestro

Operating via a mechanism kernel without background services, this harness manages long-running agents through Supervisor, Lead, and Peer roles. It facilitates structured memory and cross-feature learning, requiring Herdr for hosting Supervisor rooms and lane panes.

esaradev / icarus-plugin

This plugin establishes cross-instance shared memory using markdown files to capture high-value decisions and outcomes. It provides a specialized pipeline for fine-tuning and transitioning to replacement models based on recorded work.

smartcontractkit / chainlink-agent-skills

Built on the Agent Skills specification, this project enables interaction with oracle networks and smart contracts, including CCIP, VRF, and Data Feeds. It provides specialized capabilities for CRE and ACE services to ensure blockchain interoperability.

Hermes-brasil / hermes-brasil

This community resource offers installation guides and skills formatted for the agentskills.io standard specifically in Portuguese. It serves as a localized hub for Hermes Agent integrations and configuration documentation.

black-forest-labs / skills

These official skills integrate FLUX.2 image and FLUX 3 video generation models with specialized modules for cinematic and archival formats. The project includes API integration and prompt optimization guidelines for audio directing and product advertising.

armelhbobdad / bmad-module-skill-forge

This tool converts repositories and developer discourse into version-pinned skills that link instructions to specific file lines at pinned commits. It generates audit trails and provenance maps to ensure the integrity of generated skills.

chigwell / skilldock.io

This registry provides a CLI and Python client for installing reusable AI skills with recursive dependency resolution. It also incorporates commerce features by supporting TON payments for skill access.

tiann / execplan-skill

Designed for complex multi-step tasks, this skill provides autonomous execution with real-time progress tracking. It ensures operational safety through built-in rollback procedures and checkpoints for recovery during long-running processes.

supernovae-st / nika

This project introduces a local-first workflow language that audits AI operations for costs, permissions, and types before execution. It generates tamper-evident, hash-chained receipts for every run, ensuring high-integrity execution via a single Rust binary.

adnw-vinc / hermes-nextcloud

This skill enables Hermes to manage files, calendars, and contacts through standard WebDAV and CalDAV protocols. It features a guided setup script for secure HTTPS communication using Nextcloud App Passwords.

cablate / Agentic-MCP-Skill

A progressive MCP client that utilizes a three-layer lazy loading architecture to minimize token consumption. It employs a socket-based daemon for persistent connections and incremental discovery of tool schemas.

willingning-coder / eagle-eye

This skill provides a five-layer retrieval system that combines hard triggers, semantic embeddings, and RRF fusion to narrow skill lists. It reduces token usage by filtering skills before LLM calls and supports graceful degradation if dependencies are missing.

amanning3390 / hermeshub

A community hub for browsing and installing skills that implements the Agentic Resource Discovery (ARD) v0.9 specification. It operates autonomously on NVIDIA infrastructure and integrates federated search across GitHub and Hugging Face.

EntangledQuantum / Life_OS

This personal execution OS uses a local SQLite database to manage habits and study blocks without cloud synchronization. It allows an agent to handle system design via the Model Context Protocol while the user executes tasks through a tapping interface.

Sahil-SS9 / hermaguard

A read-only code review skill that employs three parallel subagents to perform adversarial and integration analysis. It combines deterministic pre-scans using tools like Semgrep and Bandit with verified findings from a hardened sandbox.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin rewrites and scores prompts across multiple interfaces, including CLI, Discord, and Telegram, to reduce token usage by up to 80%. It supports 97 languages and evaluates prompt quality across five specific dimensions.

teixeirazeus / fablize-for-hermes

This project implements systematic investigation protocols and multi-story task decomposition with mandatory evidence-based verification gates. It includes a Python-based goal engine to maintain persistent task states and prevent early-stop errors.

Sahil-SS9 / hermes-simplify-swarm

A multi-agent code simplification skill that uses parallel agents focused on hygiene, clarity, and correctness across five programming languages. It features a tiered application process that requires an approval gate before changes are finalized.

PederHP / skillsdotnet

A .NET implementation of the agentskills.io pattern that utilizes SKILL.md files for progressive disclosure. It integrates with Microsoft.Extensions.AI to facilitate tool-based skill loading and automatic directory registration.

handnewb / hermes-cybersec-lab

This turnkey lab provides over 2,000 skills and 131 tools for network forensics and exploitation based on CVE data. it integrates 28 cybersecurity frameworks, including MITRE ATT&CK and NIST, to support comprehensive security operations.

conorbronsdon / agent-skills

This toolkit provides production-tested session management to maintain memory between agent conversations and orchestrates parallel subagents for code reviews. It also includes specialized tools for worktree recovery, state drift detection, and skill scaffolding.

conorbronsdon / demo-gif-skill

This skill automates the creation of reproducible recording scripts using vhs or Playwright to generate demo GIFs for repository READMEs. It ensures all output files are optimized under 8 MB and embeds the rendered media directly into the documentation.

conorbronsdon / agent-skill-builder

This utility generates Claude Code and portable agent skills from plain language while monitoring official frontmatter specs to prevent rot. It uses CI-friendly exit codes to validate skills against runtime-specific profiles and detect structural drift.

aidevelopers2 / remoteopenclaw-mcp

This CLI and MCP server enables users to search a database of over 13,870 MCP servers and 4,384 agent skills from their terminal. It provides direct installation commands for discovered tools and integrates with compatible clients like Hermes and Cursor.

Carlo1911 / skill-evolution

This project establishes a self-improvement loop by analyzing session history to identify skill gaps and propose structured updates. It operates locally using the Python standard library and gates all changes behind deterministic and LLM-judge evaluators.

Diabloluo / hermes-hud

This local-first observability dashboard provides 11 monitoring tabs for real-time tracking of token costs, errors, and session health. It enforces a strict read-only boundary with zero outbound telemetry and supports optional incident alerts via Telegram or Feishu.

mag3nt-com / openclaw-skill

This skill automates payments for HTTP 402 responses using USDC across protocols like Pay Link, x402, and MPP. It is designed for compatibility with the OpenClaw and Hermes Agent standards.

skillseal / skillseal

This framework certifies the functional quality of AI agent skills by testing their structure, functionality, and security in isolated Docker containers. It produces cryptographically verifiable certificates using Ed25519 signatures and offers a public API for verification.

CorsenAI / hermes-windows-runtime-skills

These skills manage deterministic path routing and interpreter selection across native Windows, Git Bash, and WSL environments. The tool automatically identifies and verifies project-compatible Python runtimes without requiring new installations.

webmilmind1 / hermes-bounty-board

This plugin allows users to earn USDC on the Base network by answering support bounties without requiring accounts or API keys. It includes tools for creating bounty boards and buying context, with 85% of the payment routed to the winning wallet upon human approval.

Shine8592 / china-briefing

This skill generates multi-scale Chinese news reports ranging from global to street-level perspectives. It utilizes semantic memory to integrate user interests and produces structured summaries containing core conclusions and action suggestions.

jiawood2006 / hermes-skills

This collection provides tools for video-to-text conversion, OCR, and agent memory management compatible with the agentskills.io standard. It supports cross-platform use on macOS, Linux, and Windows depending on the specific skill selected.

This project enables Hermes Agent to access structured web data across 31 platforms by exposing 191 tools through a hosted MCP server. It includes five production-grade workflow skills and supports integration with environments such as Claude, Cursor, Goose, and OpenHands.
