breakdown

obra / superpowers

This framework implements subagent-driven development to enable autonomous task execution for coding harnesses like Hermes. It enforces strict software development methodologies, including red-green-refactor TDD and YAGNI principles, to ensure high-quality code generation.

nexu-io / open-design

A local-first system for generating web, mobile, and desktop prototypes through coding-agent CLI support. It allows Hermes Agent to function within a design and prototyping workflow across macOS and Windows desktop applications.

mukul975 / Anthropic-Cybersecurity-Skills

This project provides 817 structured cybersecurity skills across 29 domains, mapped to industry frameworks like MITRE ATT&CK and NIST CSF 2.0. It is compatible with over 26 AI platforms, offering a comprehensive security knowledge base for agents.

topoteretes / cognee

Cognee functions as a self-hosted knowledge graph engine that provides AI agents with persistent long-term memory across sessions. By combining vector embeddings with graph-based reasoning, it enables agents to perform complex searches using Python, Rust, or TypeScript clients.

Agents365-ai / drawio-skill

This skill enables the generation of editable .drawio files from natural language descriptions or Mermaid text. It features 11 diagram type presets and includes self-check and auto-fix capabilities to ensure diagram accuracy.

internet-court / internet-court-skill

Serving as a trust layer for agent-to-agent commerce, this skill facilitates natural-language mandates, delegated permissions, and escrow payments. It includes a master router and a verification layer to handle dispute resolution between autonomous agents.

conorbronsdon / avoid-ai-writing

This tool audits and rewrites content to eliminate detectable AI writing patterns using a two-pass detection process. It utilizes a 112-entry word replacement table and is compatible with Hermes, Claude Code, and Cursor.

AMAP-ML / SkillClaw

SkillClaw automates the collective evolution of agentic skills by performing deduplication and quality improvements across sessions. It synchronizes skill libraries across multiple devices and team environments, integrating with Hermes and OpenAI-compatible APIs.

wondelai / skills

This cross-platform library offers 12 metaskills designed to preserve state within a local directory for agentskills.io-compatible agents. The skills are available as spec-conformant plugins that work natively with Claude Code.

mohitagw15856 / pm-claude-skills

This repository contains 1,153 professional agent skills in plain markdown format that run natively in Hermes Agent. It also provides ready-to-paste exports for other assistants including ChatGPT, Gemini, and Cursor.

ZeroPointRepo / youtube-skills

These skills allow Hermes Agent to perform YouTube video searches, extract transcripts, and browse channels or playlists. The integration requires a TranscriptAPI key and is compatible with multiple coding environments like Windsurf and OpenClaw.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that automatically detects and proposes reusable skills by watching active workflows. It generates both SKILL.md documentation and Python scaffolds, allowing users to manage detected patterns via slash commands.

Cranot / super-hermes

This project enables Hermes Agent to generate its own analytical prompts and thinking instructions tailored to specific tasks. It includes pre-built domain-specific lenses and provides reports that highlight both findings and potential analysis blind spots.

DougTrajano / pydantic-ai-skills

This toolkit provides type-safe support for Pydantic AI through modular packages containing instructions, resources, and scripts. It utilizes progressive disclosure to improve prompt efficiency and supports both programmatic skills and remote registries.

AkoliteZA / hermes-agent-idea-workflow

This skill automates the transition from rough concepts to structured design and implementation documents. It features Lite and Full modes for different project scales and includes a spec review gate that uses PASS/FAIL evaluation models.

tlehman / litprog-skill

This skill implements literate programming by combining prose, diagrams, and source code into .lit.md files. It features a tangler to extract runnable source files and automatically synchronizes edits from source files back into the primary documentation.

ReinaMacCredy / maestro

Maestro provides a harness for long-running agents using a three-level work model and structured memory backed by files or SQLite. It includes a CLI for managing tasks and cards to facilitate a plan-approve-execute workflow.

esaradev / icarus-plugin

This plugin enables cross-instance shared memory via markdown files to capture high-value decisions and outcomes. It establishes a pipeline for fine-tuning and transitioning to replacement models based on recorded agent work.

smartcontractkit / chainlink-agent-skills

These skills allow Hermes Agent to interact with oracle networks and smart contracts using the Agent Skills specification. It supports integrations for CCIP, VRF, and Data Feeds, alongside specialized services for CRE and ACE.

Hermes-brasil / hermes-brasil

This project serves the Brazilian community by providing Hermes Agent skills, installation guides, and configuration resources in Portuguese. All skills follow the SKILL.md format and adhere to the agentskills.io standard.

black-forest-labs / skills

This repository provides official integration for FLUX image and video generation, including prompting guidelines for FLUX.1 and FLUX.2 models. It contains API documentation, code examples, and a suite of six specialized video generation skills.

armelhbobdad / bmad-module-skill-forge

This tool converts existing repositories, documentation, and developer discourse into version-pinned, agentskills.io-compliant skills. It supports Node.js and Python environments while providing provenance through file and line number citations.

chigwell / skilldock.io

This registry facilitates the discovery and installation of reusable AI skills with recursive dependency resolution. It includes a Python client and CLI, and supports commercial transactions via TON payments.

tiann / execplan-skill

This skill manages complex multi-step tasks by providing autonomous execution with real-time progress tracking. It ensures reliability through built-in checkpoints and rollback procedures for safe recovery during long-running operations.

supernovae-st / nika

This project provides a local-first workflow language that uses a four-verb YAML specification to manage AI models and tools. It audits workflows for costs and permissions before execution and generates tamper-evident, hash-chained receipts for every run.

adnw-vinc / hermes-nextcloud

This skill enables Hermes to manage files, notes, calendars, tasks, and contacts through standard WebDAV and CalDAV protocols. It ensures secure communication via HTTPS and includes a guided setup script for credential validation.

cablate / Agentic-MCP-Skill

This progressive MCP client utilizes a three-layer lazy loading system to minimize token usage during tool discovery. It features a socket-based daemon architecture for persistent connections and incremental metadata retrieval.

willingning-coder / eagle-eye

Eagle-eye implements a five-layer retrieval system using hard triggers, semantic embeddings, and RRF fusion to narrow skill lists. This approach reduces token usage and includes graceful degradation if specific dependencies or models are missing.

amanning3390 / hermeshub

HermesHub serves as a community hub for browsing and installing skills, fully implementing the Agentic Resource Discovery (ARD) v0.9 specification. It operates autonomously on NVIDIA infrastructure and provides federated search across GitHub and Hugging Face.

Sahil-SS9 / hermaguard

This read-only code review skill uses three parallel subagents to identify edge cases and exploits, followed by sandbox execution to verify findings. It incorporates a deterministic pre-scan using tools like Semgrep, Bandit, and ESLint to triage vulnerabilities.

EntangledQuantum / Life_OS

Life_OS is a personal execution system where an agent manages system design while the user completes tasks via a tap-based interface. It stores data locally using SQLite and connects to AI agents through the Model Context Protocol (MCP).

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin rewrites and scores prompts across various surfaces like CLI and Discord, supporting 97 languages. It is designed to reduce token usage by 20–80% while evaluating prompt quality across five specific dimensions.

teixeirazeus / fablize-for-hermes

This project implements multi-story task decomposition with mandatory evidence-based verification gates for grounded execution. It includes a systematic investigation protocol for causal debugging and a Python goal engine for persistent state management.

Sahil-SS9 / hermes-simplify-swarm

Inspired by Claude Code, this skill uses parallel agents focused on hygiene, clarity, and correctness to simplify codebases. It supports multiple languages including Rust and Go, featuring a tiered application process with a final approval gate.

PederHP / skillsdotnet

This .NET implementation of the agentskills.io pattern uses SKILL.md files to facilitate progressive disclosure of agent capabilities. It integrates with Microsoft.Extensions.AI for tool-based loading and supports automatic registration of skill directories.

handnewb / hermes-cybersec-lab

This turnkey lab provides over 2,000 skills and 131 tools for network forensics and exploitation based on real-world CVEs. It integrates 28 cybersecurity frameworks, including MITRE ATT&CK and OWASP, to support comprehensive security workflows.

conorbronsdon / demo-gif-skill

This skill automates the creation of reproducible repository demonstrations using vhs or Playwright scripts. It optimizes the resulting GIF files to remain under 8 MB and embeds them directly into the project README.

conorbronsdon / agent-skill-builder

This tool generates portable agent skills from plain language descriptions while ensuring they remain compliant with current frontmatter specifications. It includes a validator with CI-friendly exit codes to detect and report any drift from official runtime profiles.

aidevelopers2 / remoteopenclaw-mcp

This project provides a CLI and MCP server to search a database of over 13,870 MCP servers and 4,384 agent skills. It facilitates tool discovery and provides direct installation commands for compatible clients like Hermes, Cursor, and Claude Code.

mag3nt-com / openclaw-skill

This skill automates payments for HTTP 402 responses using USDC across protocols like Pay Link and x402. It is designed for compatibility with the OpenClaw and Hermes Agent standards.

skillseal / skillseal

Skillseal provides functional quality certification by testing agent skills for structure, functionality, and security within isolated Docker containers. It issues cryptographically verifiable certificates using Ed25519 signatures to confirm a skill actually works.

CorsenAI / hermes-windows-runtime-skills

These skills enable deterministic path routing and interpreter selection across native Windows, Git Bash, and WSL environments. The tool automatically identifies and verifies project-compatible Python runtimes without requiring new installations.

webmilmind1 / hermes-bounty-board

This plugin allows users to earn USDC on the Base network by answering support bounties without requiring accounts or API keys. It includes tools for creating bounty boards and buying context, with 85% of the payment routed to the winning wallet upon human approval.

Shine8592 / china-briefing

This skill generates multi-scale Chinese news briefings ranging from global events to street-level updates. It utilizes semantic memory to expand searches based on user interests and produces structured reports containing core conclusions and action suggestions.

jiawood2006 / hermes-skills

This collection provides local OCR for PDFs and images to maintain privacy alongside video-to-text transcription capabilities. It also features an e-commerce studio for batch material generation with brand overlays and AI-driven text refinement.

scavio-ai / hermes-agent

This project exposes 191 tools and five production-grade workflow skills via a hosted MCP server. It is designed to provide structured web data across 31 platforms for agents including Hermes, Claude, and Cursor.
