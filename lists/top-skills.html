breakdown

obra / superpowers

This framework implements subagent-driven development to enable autonomous task execution for Hermes Agent. It enforces technical rigor through red-green-refactor TDD and YAGNI principles while integrating with coding harnesses like Claude and Codex.

nexu-io / open-design

This local-first system provides Hermes Agent with a design and prototyping toolkit supported by a dedicated CLI. It enables the generation of visual exports including HTML, PDF, and MP4 based on a structured brand design system.

topoteretes / cognee

Cognee functions as a persistent long-term memory layer that allows agents to maintain context across multiple sessions. It transforms diverse data formats into self-hosted knowledge graphs accessible via Rust and TypeScript clients.

mukul975 / Anthropic-Cybersecurity-Skills

This library equips agents with over 800 structured cybersecurity skills mapped to industry frameworks like MITRE ATT&CK and NIST CSF 2.0. The collection is compatible with more than 26 AI platforms to support standardized security operations.

Agents365-ai / drawio-skill

This skill enables the generation of editable .drawio files from natural language descriptions or Mermaid text. It features 11 diagram presets and includes autonomous self-check and auto-fix capabilities to ensure diagram accuracy.

internet-court / internet-court-skill

This project establishes a trust layer for agent-to-agent commerce by integrating ERC-7710 permissions and x402 payments. It provides a unified skill for adjudication, escrow, and dispute resolution to connect fragmented ecosystem layers.

conorbronsdon / avoid-ai-writing

Compatible with Hermes and Claude Code, this tool audits and rewrites content to remove detectable AI patterns. It utilizes a two-pass detection process and a 112-entry word replacement table to refine agent-generated text.

AMAP-ML / SkillClaw

SkillClaw automates the collective evolution of agent capabilities by deduplicating and improving skills across sessions. It synchronizes skill libraries across multiple devices and team environments for platforms like Hermes and Codex.

wondelai / skills

This cross-platform library provides spec-conformant plugins and 12 metaskills designed to preserve state within a local directory. It is built for compatibility with Claude Code and agentskills.io-compatible agents.

mohitagw15856 / pm-claude-skills

This repository offers a collection of 1,099 professional skills that run natively in Hermes Agent and Claude Code. It includes ready-to-paste exports to facilitate the use of these professional capabilities across other AI assistants.

ZeroPointRepo / youtube-skills

Powered by TranscriptAPI, this skill set allows Hermes Agent to perform YouTube searches and retrieve data from transcripts, channels, and playlists. It follows the standard Agent Skills format for broad compatibility with coding environments.

Romanescu11 / hermes-skill-factory

This meta-skill plugin monitors active workflows to automatically detect and propose reusable skill patterns. It generates both Python plugin scaffolds and SKILL.md documentation, allowing users to manage new skills via slash commands.

Cranot / super-hermes

This project enables Hermes Agent to generate custom thinking instructions and analytical lenses for specific tasks. It reports findings alongside an analysis of potential blind spots to improve the agent's self-evaluation.

DougTrajano / pydantic-ai-skills

This toolkit provides type-safe support for modular packages containing instructions, resources, and scripts. It utilizes progressive disclosure to maintain prompt efficiency and supports both programmatic skills and remote registries.

AkoliteZA / hermes-agent-idea-workflow

This workflow skill converts rough concepts into structured design documents and implementation handoffs. It features Lite and Full modes for varying project complexities and includes a spec review gate with PASS/FAIL evaluation models.

tlehman / litprog-skill

This skill implements literate programming by weaving prose, diagrams, and source code into .lit.md files. It includes a tangler to extract runnable source files and automatically syncs edits back to the original documentation.

ReinaMacCredy / maestro

Maestro provides a harness for long-running agents using a three-level work model and structured memory via file-backed or SQLite cards. It facilitates cross-feature learning and includes a CLI for managing tasks and card-based memory.

esaradev / icarus-plugin

This plugin enables cross-instance shared memory through markdown files to capture high-value decisions and outcomes. It establishes a pipeline for fine-tuning and transitioning to replacement models based on recorded work history.

smartcontractkit / chainlink-agent-skills

This project provides interoperable skills for interacting with oracle networks and smart contracts, including CCIP, VRF, and Data Feeds. It follows the Agent Skills specification and includes specialized support for CRE and ACE services.

Hermes-brasil / hermes-brasil

This community resource offers installation guides and skills in the SKILL.md format specifically for Portuguese-speaking users. It adheres to the agentskills.io standard to ensure compatibility with the broader Hermes ecosystem.

black-forest-labs / skills

These official skills provide API integration and prompting guidelines for FLUX.1 and FLUX.2 image generation models. The suite also includes six specialized skills for FLUX 3 video generation tasks.

armelhbobdad / bmad-module-skill-forge

This tool converts repositories, documentation, and developer discourse into version-pinned, agentskills.io-compliant skills. It supports Node.js and Python environments while providing provenance through file and line number citations.

chigwell / skilldock.io

This registry facilitates the discovery and installation of reusable AI skills with recursive dependency resolution. It includes a Python client, a CLI, and commerce features powered by TON payments.

tiann / execplan-skill

This skill enables autonomous execution of complex, multi-step tasks with real-time progress tracking. It features built-in checkpoints and rollback procedures to allow for safe recovery during long-running operations.

supernovae-st / nika

This project introduces a workflow language for AI that uses a single file and four verbs to define intent as code. It supports local-first execution with any LLM and provides static auditing alongside tamper-evident execution receipts.

adnw-vinc / hermes-nextcloud

This skill enables Hermes to manage files, notes, calendars, tasks, and contacts through standard WebDAV and CalDAV protocols. It ensures secure communication via HTTPS and includes a guided setup script for credential validation.

cablate / Agentic-MCP-Skill

This progressive MCP client utilizes a three-layer lazy loading architecture to minimize token usage during skill discovery. It features a socket-based daemon for persistent connections and incrementally discovers server metadata and tool schemas.

willingning-coder / eagle-eye

This retrieval system employs a five-layer approach, including hard triggers and semantic embeddings, to narrow skill lists before LLM calls. It reduces token consumption and features graceful degradation if specific embedding models or dependencies are unavailable.

Sahil-SS9 / hermaguard

This read-only code review tool uses parallel subagents to identify edge cases and exploits, which are then verified through sandbox execution. It integrates deterministic pre-scans using tools like Semgrep and Bandit to triage findings as verified or refuted.

EntangledQuantum / Life_OS

Designed as an ADHD-friendly execution system, this project allows an agent to manage system design while the user completes tasks via a tap-based interface. It stores data locally using SQLite and connects to AI agents through the Model Context Protocol.

amanning3390 / hermeshub

This hub implements the Agentic Resource Discovery v0.9 specification to provide community skill browsing and one-click installation. It operates autonomously on NVIDIA infrastructure and features federated search across GitHub and Hugging Face.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin rewrites and scores prompts across various interfaces like Discord and Telegram while tailoring outputs to specific model families. It preserves non-English prompts through specialized heuristics and tracks token savings in a local database.

teixeirazeus / fablize-for-hermes

This adaptation implements multi-story task decomposition with mandatory evidence-based verification gates to prevent early-stop errors. It includes a systematic investigation protocol for causal debugging and a Python engine for persistent task state management.

Sahil-SS9 / hermes-simplify-swarm

Inspired by Claude Code, this skill utilizes three parallel agents focused on hygiene, clarity, and correctness to simplify code across multiple languages. It features a tiered application process that includes a mandatory approval gate for changes.

PederHP / skillsdotnet

This C# and .NET implementation of the agentskills.io pattern supports progressive disclosure via SKILL.md files. It integrates with Microsoft.Extensions.AI for tool-based loading and automatically registers common skill directories.

handnewb / hermes-cybersec-lab

This turnkey laboratory provides over 2,000 skills and 131 tools for network forensics and exploitation based on real-world CVEs. it integrates 28 cybersecurity frameworks, including MITRE ATT&CK and NIST, to support comprehensive security workflows.

aidevelopers2 / remoteopenclaw-mcp

This tool enables terminal or AI agent access to a database of over 13,870 MCP servers and 4,384 agent skills. It integrates with clients like Hermes to provide direct installation commands for discovered plugins and tools.

mag3nt-com / openclaw-skill

This skill automates payments for HTTP 402 responses using USDC across protocols like Pay Link and x402. It is designed for compatibility with the agentskills.io standard and the Hermes Agent ecosystem.

skillseal / skillseal

Skillseal provides a quality seal by testing the structure, functionality, and security of agent skills within isolated Docker environments. It generates cryptographically verifiable Ed25519 certificates to prove a skill actually works as intended.

Shine8592 / china-briefing

This generator produces multi-scale Chinese news reports ranging from global events to street-level updates for Hermes Agent. It utilizes semantic memory to align search results with user interests and provides structured action suggestions.

jiawood2006 / hermes-skills

This collection offers specialized utilities for video-to-text transcription, local OCR for privacy-focused document processing, and AI-driven text refinement. It also includes an e-commerce studio for batch material generation featuring brand overlays.

CorsenAI / hermes-windows-runtime-skills

This skill set manages deterministic path routing and Python interpreter selection across Windows, Git Bash, and WSL environments. It ensures Hermes Agent can correctly identify and utilize existing project-compatible runtimes without new installations.
