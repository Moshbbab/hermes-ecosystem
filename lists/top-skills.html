breakdown

obra / superpowers

This framework implements a subagent-driven development methodology to execute engineering tasks autonomously. It enforces a structured workflow of brainstorming, planning, and TDD while integrating as a plugin for various coding agents and CLI tools.

nexu-io / open-design

A local-first design and prototyping system that supports 26 CLI executables, including Hermes Agent and Claude Code. It features a sandboxed iframe for live iterations and exports artifacts to formats such as HTML, PDF, and MP4.

mukul975 / Anthropic-Cybersecurity-Skills

This repository provides 818 structured skills across 34 security domains, mapped to frameworks like MITRE ATT&CK, ATLAS, and NIST AI RMF. The library is compatible with over 26 AI platforms to enhance agent security capabilities.

topoteretes / cognee

Cognee serves as a self-hosted knowledge graph engine that provides agents with persistent long-term memory across sessions. It combines vector embeddings with graph-based reasoning and offers clients for Python, Rust, and TypeScript.

Agents365-ai / drawio-skill

This skill enables agents to generate editable .drawio files from natural language descriptions using 11 diagram type presets. It includes self-check and auto-fix capabilities and can convert Mermaid text into diagram formats.

internet-court / internet-court-skill

Acting as a trust layer for agent-to-agent commerce, this skill facilitates natural-language mandates, delegated permissions, and x402 payments. It includes a master router and connector skills alongside a verification and dispute resolution layer.

conorbronsdon / avoid-ai-writing

This tool audits and rewrites content to eliminate detectable AI patterns using a two-pass detection system. It supports Rewrite, Detect, and Edit-in-place modes with optional voice profiles for different professional tones.

AMAP-ML / SkillClaw

SkillClaw enables collective skill evolution by supporting skill merging and cross-pollination across agents like Hermes and QwenPaw. It provides a bilingual dashboard for inspecting session traces and managing evolving skill sets.

wondelai / skills

A cross-platform library featuring 51 expert frameworks and 14 guided metaskills compatible with Claude Code and Codex. It maintains session state within the project's documentation directory to support persistent agent workflows.

mohitagw15856 / pm-claude-skills

This collection contains 1,153 markdown-based skills for professional and life tasks that run natively in Hermes Agent and Claude Code. It includes specific integrations for platforms such as Slack, Telegram, Obsidian, and n8n.

ZeroPointRepo / youtube-skills

This skill set allows agents to perform video searches, extract transcripts, and browse channels or playlists on YouTube. It is compatible with Hermes Agent, OpenClaw, and Cursor, requiring a TranscriptAPI key for operation.

Romanescu11 / hermes-skill-factory

A meta-skill plugin that automatically detects reusable patterns in active workflows to propose new skills. It generates both SKILL.md documentation and Python scaffolds, allowing users to manage these skills via slash commands.

Cranot / super-hermes

This project enables Hermes Agent to generate custom thinking instructions and analytical prompts for specific tasks. It utilizes pre-built analytical lenses across various domains and reports findings alongside a dedicated analysis of potential blind spots.

DougTrajano / pydantic-ai-skills

This toolkit provides type-safe support for modular packages containing instructions, resources, and scripts for Pydantic AI. It implements progressive disclosure to improve prompt efficiency and supports both remote registries and programmatic skills.

AkoliteZA / hermes-agent-idea-workflow

This skill automates the transition from rough concepts to structured design and implementation documents. It features Lite and Full modes to accommodate different project complexities and includes a spec review gate with PASS/FAIL evaluation models.

tlehman / litprog-skill

This skill implements literate programming by weaving prose, diagrams, and source code into .lit.md files. It includes a tangler to extract runnable source files and automatically syncs edits from those files back into the primary literate document.

ReinaMacCredy / maestro

Maestro acts as a harness for long-running agents using a mechanism kernel that operates without a background service. It organizes workflows through four distinct roles—Human, Supervisor, Lead, and Peer—and requires Herdr for hosting Supervisor rooms.

esaradev / icarus-plugin

This plugin facilitates cross-instance shared memory by capturing high-value decisions and outcomes in markdown files. It establishes a pipeline for fine-tuning models and transitioning to replacement models based on recorded work history.

smartcontractkit / chainlink-agent-skills

These skills enable Hermes Agent to interact with oracle networks and smart contracts via CCIP, VRF, and Data Feeds. The project follows the Agent Skills specification and includes specialized modules for CRE and ACE services.

Hermes-brasil / hermes-brasil

This repository serves the Brazilian community by providing Hermes Agent skills, installation guides, and configuration resources in Portuguese. All skills are provided in the SKILL.md format and adhere to the agentskills.io standard.

black-forest-labs / skills

These official skills integrate FLUX.2 image and FLUX 3 video generation models into agent workflows. The project includes specialized modules for prompt optimization, audio directing, and specific visual formats like cinematic inserts and product ads.

armelhbobdad / bmad-module-skill-forge

This tool converts repositories, documentation, and developer discussions into agentskills.io-compliant skills. It ensures precision by linking instructions to specific file lines at pinned commits and generates audit trails for provenance.

chigwell / skilldock.io

Skilldock.io functions as a registry for reusable AI skills, offering a Python client and CLI for installation. It manages complex environments through recursive dependency resolution and supports commerce features using TON payments.

tiann / execplan-skill

This skill manages complex, multi-step tasks by providing autonomous execution with real-time progress tracking. It ensures operational safety through built-in checkpoints and rollback procedures for recovery from execution errors.

supernovae-st / nika

Nika introduces an 'Intent as Code' workflow language that audits permissions, costs, and types before executing locally via a single Rust binary. It ensures accountability by generating hash-chained, tamper-evident receipts for every run.

adnw-vinc / hermes-nextcloud

This skill enables Hermes to manage files, notes, calendars, and contacts through standard WebDAV and CalDAV protocols. It features a guided setup script for secure HTTPS communication using Nextcloud App Passwords.

cablate / Agentic-MCP-Skill

This progressive MCP client utilizes a three-layer lazy loading architecture to minimize token usage during tool discovery. It employs a socket-based daemon to maintain persistent connections and incrementally fetch server metadata.

willingning-coder / eagle-eye

Eagle-eye provides a five-layer retrieval system that combines hard triggers, semantic embeddings, and RRF fusion to narrow skill lists before LLM calls. The system is designed for resilience, offering graceful degradation if embedding models or specific dependencies are unavailable.

amanning3390 / hermeshub

HermesHub serves as a community platform for browsing and installing skills, fully implementing the Agentic Resource Discovery (ARD) v0.9 specification. It operates autonomously on NVIDIA infrastructure and integrates federated search across GitHub and Hugging Face.

EntangledQuantum / Life_OS

Life_OS is a personal execution system where an agent manages system design while the user completes tasks via a tap-based interface. It stores all data locally in SQLite and connects to AI agents through the Model Context Protocol.

Sahil-SS9 / hermaguard

This read-only code review skill uses three parallel subagents to perform adversarial, edge-case, and integration analysis. It combines deterministic pre-scans with proof-of-concept execution in a hardened sandbox to verify findings.

Sahil-SS9 / hermes-multichannel-prompt-optimizer

This plugin optimizes prompts across multiple surfaces like CLI and Discord, scoring them across five quality dimensions. It supports 97 languages and claims to reduce token usage by 20–80% per rewrite.

teixeirazeus / fablize-for-hermes

Fablize adapts verified procedures for task decomposition, requiring evidence-based gating and systematic investigation protocols. It includes a Python goal engine to maintain persistent state during complex causal debugging.

Sahil-SS9 / hermes-simplify-swarm

Inspired by Claude Code, this skill uses a swarm of Hygiene, Clarity, and Correctness agents to simplify code in five major programming languages. It features a tiered application process that includes a mandatory approval gate for changes.

PederHP / skillsdotnet

This .NET implementation of the agentskills.io pattern enables tool-based skill loading via Microsoft.Extensions.AI. It supports progressive disclosure through SKILL.md files and automatically registers common agent skill directories.

handnewb / hermes-cybersec-lab

This turnkey lab provides Hermes with over 2,000 skills and 131 tools for network forensics and exploitation. It integrates 28 cybersecurity frameworks, covering CVE-driven scenarios ranging from 2015 to 2026.

conorbronsdon / agent-skills

This project provides production-tested session management to maintain memory between agent conversations and orchestrates parallel subagents for architectural reviews. It includes specialized tools for worktree recovery, state drift detection, and skill scaffolding.

conorbronsdon / demo-gif-skill

This skill automates the creation of reproducible recording scripts using vhs or Playwright to generate demo GIFs for repository READMEs. It ensures all generated files are optimized under 8 MB and embeds them directly into the documentation.

conorbronsdon / agent-skill-builder

This tool generates portable agent skills from plain language while monitoring official frontmatter specs to prevent bit rot. It includes a validator with CI-friendly exit codes to ensure skills remain compliant with runtime-specific profiles.

Carlo1911 / skill-evolution

This host-agnostic framework creates a self-improvement loop by analyzing session history to identify and propose new skill coverage gaps. It gates all updates behind deterministic and LLM-judge evaluators and operates locally using the Python standard library.

aidevelopers2 / remoteopenclaw-mcp

This CLI and MCP server enables agents to search a database of over 13,870 MCP servers and 4,384 skills. It provides direct installation commands for discovered tools and integrates with compatible clients like Hermes and Cursor.

CorsenAI / hermes-windows-runtime-skills

This project enables deterministic path routing and Python interpreter selection across Windows, Git Bash, and WSL environments. It ensures file operations use environment-specific syntax without requiring new software installations.

Diabloluo / hermes-hud

This local-first observability dashboard provides 11 monitoring tabs for tracking token costs, errors, and session health in real-time. It enforces a strict read-only boundary with zero outbound telemetry and supports optional incident alerts via Telegram or Feishu.

mag3nt-com / openclaw-skill

This skill automates USDC payments for HTTP 402 responses using protocols such as Pay Link, x402, and MPP. It is designed for compatibility with the agentskills.io standard and the Hermes Agent.

skillseal / skillseal

This utility certifies the quality of AI agent skills by testing their structure, functionality, and security within isolated Docker containers. It produces cryptographically verifiable certificates using Ed25519 signatures to confirm a skill actually works.

webmilmind1 / hermes-bounty-board

This plugin allows users to earn USDC on the Base network by answering support bounties without requiring an account or API key. It includes tools for listing bounties and creating boards, with payments settled after human approval.

Shine8592 / china-briefing

This skill generates multi-scale Chinese news reports ranging from global to street-level perspectives. It utilizes semantic memory to integrate user interests and applies quality gates to produce structured reports with actionable suggestions.

jiawood2006 / hermes-skills

This collection provides tools for video-to-text conversion, OCR, and agent memory management across macOS, Linux, and Windows. It adheres to the agentskills.io and Hermes Agent standards for cross-platform compatibility.

scavio-ai / hermes-agent

This project enables Hermes Agent to access structured web data across 31 platforms by exposing 191 tools through a hosted MCP server. It includes five production-grade workflow skills and supports integration with environments such as Claude, Cursor, Goose, and OpenHands.
